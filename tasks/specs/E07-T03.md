## Objective

Deliver atomic event publishing: facts commit iff the transaction commits, with at-least-once redelivery and per-aggregate ordering through the `EventPublisher` port.

## Scope

### In Scope

- `postgres/outbox/store.go`: same-transaction envelope writer (tables from 000002).
- `postgres/outbox/poller.go`: claim with `FOR UPDATE SKIP LOCKED`, publish via `port.EventPublisher`, mark delivered, backoff + alert hooks.
- Dedupe guards: event identity + `(aggregate_id, aggregate_version)` uniqueness.
- Explicit aggregate/partition sequences define order; timestamp order does not.

### Out of Scope

- Outbox tables (E07-T01, 000002); transport/broker topology (E08); durable inbox consumer side (E08-T04 proves effectively-once effects).
- Saga orchestration (E06-T07 owns); webhook delivery (E08-T05).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E07-T03-R01 | The writer MUST persist envelope rows in the caller's transaction (same commit as state). | must |
| E07-T03-R02 | The poller MUST claim rows with `FOR UPDATE SKIP LOCKED`, publish through `EventPublisher`, and mark success; failures MUST back off and surface for alerting. | must |
| E07-T03-R03 | Duplicate `(aggregate_id, aggregate_version)` MUST be rejected (dedupe guard). | must |
| E07-T03-R04 | Delivery MUST be at-least-once; ordering per aggregate MUST follow the aggregate sequence, never wall-clock order. | must |
| E07-T03-R05 | Crash between commit and publish MUST redeliver after restart (no loss). | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E07-T03-S01 | Committed outbox row, publisher down | Poller runs, then publisher recovers | Redelivered after restart; delivered_at set once |

## Invariants and Failure Semantics

- Facts are immutable once committed; the poller never edits payloads.
- Unknown publish outcome ⇒ row stays claimable (at-least-once, consumer idempotent on fact identity).
- Backoff is jittered; consecutive failures emit an alert hook call (no silent stall).
- Poller shutdown is graceful (context cancel stops after the in-flight batch).
