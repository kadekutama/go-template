## Objective

Ship pure tenant-hierarchy rules (acyclic parent links, depth limit, explicit grants) plus FX-aware consolidated balance roll-ups that unblock E03-T09 platform splits.

### Out of Scope

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E05-T02-R01 | Links MUST reject self-parent (`HIERARCHY_SELF_PARENT`), empty IDs (`HIERARCHY_ID_REQUIRED`), and any cycle (`HIERARCHY_CYCLE`); depth beyond `MaxTenantHierarchyDepth` (5) MUST fail `HIERARCHY_DEPTH_EXCEEDED`. `ValidateHierarchy` MUST be deterministic on the same input. | must |
| E05-T02-R02 | Consolidation MUST sum converted children: same-asset amounts pass through; cross-asset amounts MUST convert via supplied `FxRate` at `At` using `Convert` (stale/invalid/missing rate → `FX_*` error, never float). The rate pair MUST convert child asset → base asset (`Pair.Base == child`, `Pair.Quote == base`); mismatched pairs MUST fail `FX_RATE_MISMATCH`. Overflow MUST fail `CONSOLIDATION_OVERFLOW`. Empty children MUST fail `CONSOLIDATION_EMPTY`. | must |
| E05-T02-R03 | Cross-child transfers without an explicit per-child grant MUST fail `HIERARCHY_GRANT_REQUIRED` (`ValidateTransferGrant`); parent read access MUST require an explicit grant per child (`ValidateReadGrant`, failing `HIERARCHY_GRANT_REQUIRED`). Empty/whitespace child IDs MUST fail `HIERARCHY_ID_REQUIRED`. Grants are caller-supplied `map[string]bool` keyed by child tenant ID. | must |
| E05-T02-R04 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Invariants and Failure Semantics

- Hierarchy is a DAG enforced purely; persistence enforces FKs separately (E07).
- FX uses fixed-point numerator/denominator + half-up; floats forbidden. Rate staleness uses caller `At`.
- Grants are explicit strings; empty child ID never passes. Stable codes: `HIERARCHY_*`, `FX_RATE_MISSING`, `CONSOLIDATION_*`.
- Checked int64 arithmetic; overflow errors, never wraps.
