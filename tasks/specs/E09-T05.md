# Task Specification: E09-T05 — OpenBao secrets provider (dynamic DB credentials + KV)

**Task:** E09-T05
**Spec Status:** ready
**Author:** muse-spark
**Reviewer:** kadekutama
**Last Updated:** 2026-09-23

## Objective

Deliver runtime secrets behind `port.SecretStore` with OpenBao v2.6.2 wire-compat (Vault API), KV reads, 1h dynamic DB leases with background renewal, and `{{ secret:path }}` resolution for the config loader.

## Scope

### In Scope

- `internal/infrastructure/secrets/openbao/` package: client (token/AppRole, auto-renew seam), KV loader, `dynamic_db.go` (ephemeral `app_user` lease + renewal), TTL cache with background refresh, `Module() fx.Option`.
- HTTP seam (`HTTPDoer`) so unit tests run with `httptest` fakes and zero vendor credentials; no new `go.mod` dep (stdlib HTTP against Vault/OpenBao API).
- Unit tests (missing-secret boot error with path, rotation/renewal without restart, cancel).

### Out of Scope

- Transit encryption itself (E09-T06), compose cluster topology (E17), config-loader `{{ secret: }}` wiring beyond the resolver function (E01-T03 consumes).

## Normative Inputs

- `tasks/epics/E09-identity-security.md#E09-T05` for the backlog boundary.
- `SPEC.md §7.7` (dynamic leases, `{{ secret: }}` refs) and `docs/architecture/ADR-016-secrets-management-openbao.md`.
- `internal/application/port/secrets.go` (`Secret`, `SecretStore` contract).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E09-T05-R01 | `Get` MUST be strongly consistent per name; a miss MUST fail with the secret path in the error (boot fails loudly). | must |
| E09-T05-R02 | Dynamic DB credentials MUST be leased ephemeral (1h) with background renewal before TTL without restart. | must |
| E09-T05-R03 | Values MUST NOT be logged, embedded in errors beyond the name/path, or cached beyond TTL; callers zero slices when done. | must |
| E09-T05-R04 | Rotation MUST be transparent to callers behind the name (version bump served on next `Get`/refresh). | must |
| E09-T05-R05 | The adapter MUST implement `port.SecretStore` exactly and MUST expose `Module() fx.Option`. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E09-T05-S01 | Known secret (fake server) | `Get` | Value + expiry, no secret bytes in error |
| E09-T05-S02 | Missing secret | `Get` | Error names the secret path |
| E09-T05-S03 | Lease near expiry | Background refresh | Renewed without restart; new version served |
| E09-T05-S04 | Canceled context | `Get` | Context error |

## Interfaces and Data

```go
// openbao.Params{Address, Token/AppRole seam, HTTPClient HTTPDoer, DefaultTTL, Clock}
// openbao.NewStore(OpenBaoParams) (*Store, error); Get(ctx, tenant, name) (port.Secret, error)
// DBCredentials{Username, Password, LeaseID, Renewable, LeaseDuration}; LeaseDB(ctx, role) (DBCredentials, error); RenewLease(ctx, id) error
// ResolveReference(ref "{{ secret:path }}") (path string, ok bool)
// Sentinel errors: ErrSecretNotFound (wraps path), ErrLeaseFailed
// Module() fx.Option
```

## Invariants and Failure Semantics

- Misses are caller errors, never silent empty values; rotation never changes the lookup name.
- Renewal failures surface for the caller to fail closed; no stale-beyond-TTL serve.

## Change Surface

**Owns:** `internal/infrastructure/secrets/openbao/**` + unit tests.
**Coordinates:** `internal/application/port/secrets.go` (read-only), `internal/infrastructure/config/` resolver hook (read-only reference).
**Must Not Touch:** `internal/domain/**`, JWT/crypto/audit packages.

**Amendment 2026-09-23 (durable-boundary review, ADR-020):** The hand-rolled
TTL map (`cache.go`) is deleted — every `Get` is a strong read against OpenBao
(no app mutex, no app memory). Callers cache boot config themselves.
`ResolveReference` (strings stdlib) is unchanged.
**Amendment 2026-10-01 (GLM review fix round, CR-010 + R02):** `NewStore`
rejects empty `DBMount` (no silent "database" default). Transport errors,
non-404 statuses, and decode failures now map to distinct `ErrSecretUnavailable`
(still fail-closed) instead of overreaching `ErrSecretNotFound`. R02's
"background renewal" sentence is superseded: renewal is explicit `RenewLease`
with refresh-on-read and no background goroutine; the E14 cron consumes renewal.
Rollback: restore the mount default and the single sentinel.
