## Objective

Define the non-core application contracts that change at a different rate from the ledger kernel: one inbound use-case contract per extended bounded context plus provider, security, cache, messaging, and worker ports — with mockery wiring so every E07–E10 adapter and E06 handler builds against compiling mocks.

## Scope

### In Scope

- `internal/application/port/usecase_{account,transfer,payment,compliance,tenant}.go`: one inbound use-case interface per extended bounded context with minimal request/response structs (domain valueobjects + primitives only).
- `internal/application/port/{repository_query,payment_processor,fx_provider,secrets,cache,ratelimiter,aml,storage,lock,token,oauth,apikey,crypto,audit,statements,notify,webhooks,consumer}.go`: narrow outbound ports with timeout, retry, idempotency, consistency, and sensitive-data rules documented per method.
- `.mockery.yaml` + `make generate-mocks` target wiring mockery over `internal/domain/repository` and `internal/application/port`; generated `test/mock/...` compiling and lint-clean.
- `check-tasks.py --ports` green (adapter tasks name their ports — already satisfied by epic texts; this task keeps it green).
- Contract test proving no infrastructure/provider/SDK type crosses the port boundary.

### Out of Scope

- Handler implementations (E06-T01–T05/T11/T13 implement the use-case contracts), sagas (E06-T07), DTOs, adapter implementations (E07–E10), protobuf/GraphQL/OpenAPI generation (existing `make generate` untouched).

## Interfaces and Data

- Use-case files define request/response structs + one interface each (see Scope filenames; full signatures in code).
- Provider ports: `PaymentProcessor{Charge,Refund,GetStatus,CompleteChallenge}`, `FxRateProvider{GetRate}`, `SecretStore{Get}`, `Cache{Get,Set,Delete}`, `RateLimiter{Allow}`, `ScreeningProvider{Screen}`, `ObjectStorage{Put,Get,Delete,SignedURL}`, `DistributedLock{Acquire}` + `Lock{Release,Refresh}`, `TokenIssuer{Issue,Verify}`, `OAuthProvider{AuthURL,Exchange}`, `APIKeyStore{Create,Verify,Revoke}`, `EnvelopeCrypto{Encrypt,Decrypt}`, `AuditLogger{Record}`, `StatementParser{Parse}`, `Notifier{Send}`, `WebhookDispatcher{Dispatch}`, `MessageConsumer{Run}` + `Message`.
- `repository_query.go`: `PostingFilter` + `PostingQuery{Search}` for filtered read models.

## Invariants and Failure Semantics

- Narrow by consumer: read ports cannot write; cache is never authoritative for spend decisions; secrets never land in logs/errors.
- Unknown provider outcomes surface as errors for status resolution first (no blind retry documented per method).
- Timeout/retry ownership: callers set deadlines via ctx; adapters honor them; ports only document the contract.
