## Objective

Let reviewer and implementer converse in the same review file through strict
section ownership, so replies, adjudication, and history live in one place
without write conflicts.

## Scope

### In Scope

- SDD §3.4: shared-file rule — implementer appends only under
  `### Implementer reply`, reviewer owns everything else and never edits
  reply text; implementer packets coordinate the review path; E09 handoff
  replies grandfathered as valid history.
- Handoff template: `## Code Review` becomes link-plus-pointer (replies live
  in the report).
- Reviewer prompt: adjudication reads in-file replies; quote-don't-edit rule.
- AGENTS.md paragraph: reply location updated to the shared file.
- Task index/progress totals.

### Out of Scope

- Frontmatter, validator, review template, or other SDD section changes.
- Moving E09's already-relocated replies a second time.
- Any implementation (non-test Go), migration, contract, or E09 change.
