**Spec Status:** ready  
**Author:** opencode-agent

**Last Updated:** 2026-09-14

## Objective

Create the single JSON choke point (`pkg/jsonparser`, stdlib-backed) so the
codec stays swappable, and prove by test that no other package imports a
concrete codec directly.

## Scope

### In Scope

- `pkg/jsonparser/json.go`: `Marshal/Unmarshal/Get` over **Sonic
  (`sonic.ConfigStd`, stdlib-compatible profile) v1.15.4** — ADR-012 owner
  directive; v1.12.0 does not link on Go 1.27 (verified), so the pin moved to
  the newest compatible release. API and observable behavior unchanged
  (existing tests are the compatibility proof).
- `pkg/jsonparser/json_test.go`: round-trip (incl. integer-minor money shapes
  and large payloads), `Get` traversal + missing-path errors, benchmark record.
- `pkg/jsonparser/seam_test.go`: repository-wide import check — only
  `pkg/jsonparser` may import `encoding/json`/`encoding/base64`-adjacent codec
  externals (`github.com/bytedance/sonic`, `jsoniter`); failure names offenders.
- Package doc stating the Sonic policy (benchmark + compatibility evidence first).

### Out of Scope

- Sonic adapter (needs benchmark evidence that does not exist yet).
- Rewriting existing `encoding/json` users: T03 deliberately used koanf parsers;
  the seam test grandfather-list MUST be empty at bootstrap (prove it).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E01-T07-R01 | `Marshal/Unmarshal` MUST round-trip arbitrary structs byte-identically in observable behavior to `encoding/json`. | must |

| E01-T07-R03 | The seam test MUST fail if any non-`pkg/jsonparser` package imports `encoding/json`, `github.com/bytedance/sonic`, or `github.com/json-iterator/go`. | must |

## Interfaces and Data

`func Marshal(v any) ([]byte, error)`, `func Unmarshal(data []byte, v any) error`,
`func Get(data []byte, path ...string) ([]byte, error)` (array indices as
decimal path segments). Errors wrap stdlib errors with `jsonparser:` context.

## Invariants and Failure Semantics

- stdlib is the only backend; behavior (escapes, number formatting) matches it exactly.
- `Get` never panics on hostile input; all failures are errors.
