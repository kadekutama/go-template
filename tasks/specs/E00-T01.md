# Task Specification: E00-T01 — Initialize Go Module and Folder Structure

**Task:** E00-T01  
**Spec Status:** ready  
**Author:** repository-audit-agent  
**Reviewer:** repository-audit-agent (permitted low-risk self-review)

## Objective

Create the smallest deterministic Go repository skeleton that every later task
can compile against without choosing new paths, module identity, or binary names.

## Scope

### In Scope

- Go module identity/version, tracked directory skeleton, `.gitignore`, and five
  no-op binary entrypoints.

### Out of Scope

- Dependencies and fx wiring (E01), Make targets (E00-T02), runtime configuration,
  transports, business logic, Docker, and deployment assets.

## Normative Inputs

- `SPEC.md §2` for Go version and `SPEC.md §4` for repository layout.
- `tasks/epics/E00-foundation.md#E00-T01` for backlog acceptance criteria.
- `tasks/SDD.md` for evidence, ownership, and completion rules.
- Ready E00-T00 repository boundary and baseline; implementation cannot be claimed before it.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E00-T01-R01 | `go.mod` MUST declare `module example.com/go-template` and `go 1.27.1`; no agent may invent an organization path. | must |
| E00-T01-R02 | The directories named by E00-T01 and `SPEC.md §4` MUST exist with tracked placeholders where Go files do not yet exist. | must |
| E00-T01-R03 | Exactly five deterministic no-op `main` packages MUST exist under the declared `cmd/` binary directories and compile together. | must |
| E00-T01-R04 | `.gitignore` MUST cover build output, coverage, logs, secrets, and local Air overrides without ignoring committed example configuration. | must |
| E00-T01-R05 | The task MUST NOT create a nested Git repository or require application dependencies; `go.sum` is created only if Go produces it. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E00-T01-S01 | A clean checkout with Go 1.27.1 | `go build ./...` runs | All five no-op binaries compile with exit 0. |
| E00-T01-S02 | The created tree | `python3 tasks/scripts/check-tasks.py --dirs` runs | Every required directory is found. |
| E00-T01-S03 | The module skeleton | `go list ./cmd/...` runs | Exactly the five declared command packages are listed. |
| E00-T01-S04 | Repository root and parent Git metadata | The task is implemented | No nested `.git` directory or unrequested remote is created. |

## Interfaces and Data

The module path is the reserved reference identity `example.com/go-template`.
It is not a publishable organization claim. Import-path replacement belongs to
the future scaffolding flow; package APIs and schemas are out of scope.

## Invariants and Failure Semantics

- Running build/list checks must not require network access after the Go toolchain exists.
- Stub binaries perform no I/O, bind no ports, and return success.
- No secret/example `.env` value is committed; distributable `.env.example`
  files remain trackable.
- A Go version mismatch fails visibly; the agent must not silently downgrade the directive.

## Change Surface

**Owns:** `go.mod`, optional generated `go.sum`, `.gitignore`, five `cmd/*/main.go`
files, directory placeholders required by `SPEC.md §4`.  
**Coordinates:** existing root docs and `.opencode` directories must be preserved.  
**Must Not Touch:** business/domain code, task statuses other than E00-T01,
dependency versions, Git remotes, or parent repository metadata.
