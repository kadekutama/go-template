## Objective

Ship immutable minor-unit Money arithmetic, a versioned asset/currency registry contract, and type-safe IDs — all stdlib-only — so every later aggregate and spec computes money without floats.

## Scope

### In Scope

- `internal/domain/valueobject/money.go`: `Money{amountMinor int64, asset AssetCode}` with checked Add/Sub/MulScalar/DivScalar, Compare, overflow rejection, cross-currency `CURRENCY_MISMATCH` errors, minor-unit JSON (`amount_minor` + `asset_code`), display formatting via an explicit registry, and `AllocateLargestRemainder` (§2.13 construction helper consumed by E02-T07).
- `internal/domain/valueobject/currency.go`: `AssetCode`, `AssetKind`, `AssetInfo{code,exponent,kind,activation}`, `Registry` with `Register`/`Lookup` (no global authority; tests seed ISO examples).
- `internal/domain/valueobject/ids.go`: typed string IDs `AccountID`, `PostingID` (+ `TransactionID` public compatibility alias), `EntryID`, `TenantID`, `LedgerID`, `UserID`, `JournalID`, `PeriodID` with `String()`, `Equals()`, validating `Parse*`, and stdlib crypto/rand UUIDv7 `New*` constructors.
- Focused unit + property tests (commutativity, associativity, no precision loss).

### Out of Scope

- Account class/status/direction VOs (E02-T03 owns `account_type.go`, `account_status.go`).
- Posting/Entry/Hold aggregates (E02-T04), balance snapshots and spend specs (E02-T07 consumes Money/Registry).
- Kernel `IDGenerator` wiring (E01-T06 owns it; domain generates v7-format IDs locally via crypto/rand to stay stdlib-only).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E02-T02-R01 | Money arithmetic MUST use checked `int64` minor units; overflow on Add/Sub/Mul MUST return an error, never wrap or panic. | must |
| E02-T02-R02 | Cross-asset Add/Sub/Compare MUST fail with `CURRENCY_MISMATCH` and never panic; `0.1 + 0.2 == 0.3` equivalent MUST hold exactly in minor units. | must |
| E02-T02-R03 | All value objects MUST be immutable: unexported state, value receivers, no setters (reflection test fails if a setter appears). | must |
| E02-T02-R04 | Registry MUST be caller-supplied (no global): `Register` rejects empty codes, negative exponents, and duplicates; `Lookup` of an unknown code MUST error; Money display MUST take the registry explicitly. | must |
| E02-T02-R05 | Money JSON MUST be integer minor units (`amount_minor` + `asset_code`) via the codec-free `MoneyDTO` shape + `DTO()`/`MoneyFromDTO`; float quantities MUST NOT decode into `int64` and empty asset codes MUST error. Domain production code MUST NOT import a JSON codec (E01-T07 seam). | must |
| E02-T02-R06 | Typed IDs MUST validate canonical UUID shape on parse and round-trip `String()`/`Equals()`; generation is via the domain-owned `IDGenerator` port (kernel `UUIDGenerator` implements it implicitly; deterministic stubs in tests); the domain MUST mint nothing locally and MUST NOT import a UUID package. | must |
| E02-T02-R07 | `AllocateLargestRemainder(total, weights)` MUST implement Hare-Niemeyer (Hamilton): `floor` quotients plus one leftover unit each to the largest fractional remainders (ties → lowest index), so shares sum exactly to `total` and every share stays within one unit of its exact quota; empty weights, negative weights, and `math.MinInt64` totals MUST error. | must |
| E02-T02-R08 | Both files plus tests MUST import only the Go standard library. | must |

## Interfaces and Data

```go
// money.go
type Money struct { /* amountMinor int64, asset AssetCode (unexported) */ }
func NewMoney(amountMinor int64, asset AssetCode) (Money, error)
func (m Money) AmountMinor() int64; func (m Money) Asset() AssetCode
func (m Money) Add(o Money) (Money, error); func (m Money) Sub(o Money) (Money, error)
func (m Money) MulScalar(k int64) (Money, error); func (m Money) DivScalar(k int64) (Money, error)
func (m Money) Compare(o Money) (int, error)
func (m Money) IsZero() bool; func (m Money) IsPositive() bool
func (m Money) Format(reg Registry) (string, error)
func AllocateLargestRemainder(total int64, weights []int64) ([]int64, error)
// Canonical JSON shape (tags only; byte marshaling lives outside via pkg/jsonparser):
type MoneyDTO struct { AmountMinor int64 `json:"amount_minor"`; AssetCode AssetCode `json:"asset_code"` }
func (m Money) DTO() MoneyDTO; func MoneyFromDTO(MoneyDTO) (Money, error)
// currency.go
type AssetCode string; type AssetKind string // FIAT, CRYPTO, COMMODITY, ...
type AssetInfo struct { Code AssetCode; Exponent int; Kind AssetKind; ActiveFrom, ActiveUntil time.Time }
type Registry struct { /* unexported map */ }
func NewRegistry(infos ...AssetInfo) (Registry, error)
func (r *Registry) Register(info AssetInfo) error
func (r Registry) Lookup(code AssetCode) (AssetInfo, error)
// ids.go: AccountID, PostingID, TransactionID (= PostingID alias), EntryID,
// HoldID, TenantID, LedgerID, UserID, JournalID, PeriodID — String/Equals/Parse each,
// plus the IDGenerator port (implementations injected by callers).
```

- No wire/migration/config change; JSON shape is a domain minor-unit contract consumed later by API DTOs.
- `TransactionID` is a compile-time `= PostingID` alias (public compatibility only).

## Invariants and Failure Semantics

- Floats forbidden: no `float64` anywhere in the package (inspection check); division is truncating integer division with explicit remainder semantics documented; DivScalar by zero errors.
- Negative Money values are representable (corrections/negative availability exist downstream); entry positivity is enforced by E02-T04, not here.
- Registry carries no authority: unknown codes error at `Format`/use sites; activation windows are data, not enforced here (E03 policy owns activation).
- ID parsing is strict shape validation, not a version gate: any canonical UUID parses; `New*` always emits v7.
- Errors are ordinary Go errors; panics forbidden.
