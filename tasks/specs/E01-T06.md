## Objective

Ship the error envelope, translated messages, pagination, shutdown, goroutine,
clock, and ID helpers every later epic imports, with registry enforcement
proven by tests.

## Scope

### In Scope

- `internal/shared/kernel/error/{app_error.go,codes.go,translator.go}`:
  `AppError{Code,Message,Details,Cause,HTTPStatus}`, stable UPPER_SNAKE registry
  (`New` rejects unregistered codes), go-i18n EN/ID translation via context locale.
- `internal/shared/locale/{en.yaml,id.yaml}` message catalogs.
- `internal/shared/kernel/pagination/{page.go,cursor.go}`: offset + opaque cursor helpers.
- `internal/shared/kernel/shutdown/shutdown.go`: signal → drain → close helper.
- `internal/shared/kernel/safe/go.go`: panicking goroutines report + fail the
  owner instead of silently continuing (never ACKs financial mutations).
- `internal/shared/kernel/{clock.go,id.go}`: `Clock` (system/fixed) + `IDGenerator`
  (UUIDv7 via `google/uuid` — ADR-012 owner directive replacing ULID; same-ms
  monotonicity knowingly lost, uniqueness + v7 bits tested instead).
- New pin (recorded): `github.com/google/uuid v1.6.0` (indirect → direct).
  oklog/ulid removed by `go mod tidy` once unimported.
- New pin (recorded): `github.com/google/uuid v1.6.0` (indirect → direct,
  ADR-012) plus `gopkg.in/yaml.v3` (go-i18n v2 requires an explicitly
  registered YAML unmarshaler). SUPERSEDED: `oklog/ulid/v2 v2.1.2` was pinned
  then removed by tidy after the ADR-012 UUIDv7 switch (2026-09-14).

### Out of Scope

- Domain-specific error codes (later epics register their own via `Register`).
- Real shutdown wiring in binaries (E11/E14 consume the helper).
- Locale coverage beyond en/id (E18 owns translations).

## Invariants and Failure Semantics

- Unknown codes never construct (fail at call site, test-proven).
- `safe.Go` never acknowledges work after recovery; financial callers treat
  onPanic as unknown-outcome (retryable), never committed.
- Cursor tokens are opaque + authenticated (HMAC with caller-supplied key?
  No — keep dependency-free: base64 payload + CRC checksum; forgery ⇒ error.
  HMAC keys arrive with E09 crypto; checksum documents the interim honestly).
