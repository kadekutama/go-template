## Objective

Ship every `docs/money-flow.md §8` rule owned by the ledger domain as an executable composable spec on the E02-T01 primitives, with stable error codes and structured details — `PayoutEligibility` excluded (E03-T11 owns it with its policy/workflow), durable idempotency excluded (application/database invariant per §8).

## Scope

### In Scope

- `specification/account.go`: `AccountActive` (FROZEN→`ACCOUNT_FROZEN`, CLOSED→`ACCOUNT_CLOSED`), `SameTenant` (`TENANT_MISMATCH`).
- `specification/transaction.go`: `EntryAmountPositive` (`INVALID_ENTRY_AMOUNT`), `PostingBalancesPerCurrency` (`UNBALANCED_TRANSACTION` + per-asset totals), `PostingTemplateAllowed` (versioned operation template + account/side rules → `INVALID_POSTING_TEMPLATE`), `ValidCurrency` (pair equality or approved FX → `CURRENCY_MISMATCH`), `OriginalExists` (`ORIGINAL_NOT_FOUND`).
- `specification/transfer.go`: `TransferAmountPositive` (`INVALID_TRANSFER_AMOUNT`), `SufficientFunds(snapshot)` (`INSUFFICIENT_FUNDS` + available/required), `CaptureAmountValid` (`CAPTURE_EXCEEDS_AUTHORIZED`), `AllocationExact` (`UNBALANCED_TRANSACTION` on sum≠source).
- `specification/refund.go`: `RefundWindowValid` (`REFUND_WINDOW_EXPIRED`), `RefundAmountValid` (`REFUND_EXCEEDS_ORIGINAL`).
- `specification/period.go`: `PeriodOpen` (`PERIOD_CLOSED`).
- Table tests per spec (valid + each invalid dimension) + combinator tests.

### Out of Scope

- `PayoutEligibility` and negative-balance recovery (E03-T11 domain service).
- Repository-backed uniqueness / fingerprint equality (application/database invariant, not a spec).
- `CONCURRENT_TRANSFER` lock-contention coverage (service-level test in E03 per backlog).

## Invariants and Failure Semantics

- Specs are pure predicates over caller-supplied snapshots; they perform no I/O, locking, or time reads except comparing supplied timestamps.
- Negative/zero edge inputs fail closed with the nearest code (documented per spec); never panic, never pass vacuously except `All()`-empty (T01).
- Template + account maps are copied at construction; later caller mutation cannot change spec behavior.
