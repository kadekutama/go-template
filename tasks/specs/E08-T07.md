## Objective

Deliver the Valkey token-bucket `port.RateLimiter` with one atomic Lua script, per-dimension keys, and observability hooks for E15.

## Scope

### In Scope

- `internal/infrastructure/cache/valkey/ratelimit.lua`: atomic check-and-decrement per `ratelimit:{dimension}:{id}` with budget/window/reset semantics.
- `internal/infrastructure/cache/valkey/ratelimiter.go`: `RateLimiter` implementing `port.RateLimiter{Allow}`, per-tenant overrides from config, `ratelimit.allowed/denied` metric hooks.
- This file is the only `redis.call` Lua in the repo besides itself (review guard).

### Out of Scope

- HTTP 429 mapping/middleware chain (E11-T01/T15), rate-limit verification suite (E15-T04), cache values (E08-T01).

## Normative Inputs

- `tasks/epics/E08-cache-messaging.md#E08-T07`.
- `SPEC.md §9.4` (token bucket, dimensions, headers) and `docs/api-contracts.md §2, §12` (429 shape).
- `tasks/specs/E06-T12.md` (`RateLimiter{Allow}` decision-not-error contract).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E08-T07-R01 | Lua MUST implement a token bucket per key (hash `{tokens, ts}`, continuous refill at budget/window) and MUST return allowed + remaining + retry-after ms atomically. | must |
| E08-T07-R02 | `Allow` MUST return `RateLimitDecision{Allowed,Remaining,RetryAfter}` and MUST treat denial as a decision, never an error. | must |
| E08-T07-R03 | Keys MUST use `ratelimit:{dimension}:{id}` from E05-T03 builders with per-tenant overrides; empty key/budget/window MUST fail typed. | must |
| E08-T07-R04 | Store failure MUST surface as error (callers fail open/closed at call site); MUST emit allowed/denied hooks. | must |
| E08-T07-R05 | No other Lua scripts may exist in the repo (`grep redis.call` review guard). | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E08-T07-S01 | Fresh key, budget 5/window 60s | 5× `Allow` then 6th | First 5 allowed, 6th denied with `RetryAfter` > 0 |
| E08-T07-S02 | Over-limit burst | Sustained traffic | Never exceeds budget by >5% (Testcontainers Valkey) |
| E08-T07-S03 | Empty key / zero budget/window | `Allow` | Typed error, no Lua eval |
| E08-T07-S04 | Repo-wide grep | `grep -r "redis.call"` | Only `ratelimit.lua` matches |

## Interfaces and Data

```go
// ScriptRunner{Eval(ctx, script, keys, args...) (any, error)} narrow seam (*ValkeyClient implements; fakes in tests)
// LimiterParams{Client ScriptRunner, Logger log.Logger, OnAllow, OnDeny func(ctx context.Context, key string)}
// NewRateLimiter(LimiterParams) *RateLimiter // implements port.RateLimiter
// func (l *RateLimiter) Allow(ctx context.Context, key string, budget int64, window time.Duration) (port.RateLimitDecision, error)
// Lua keys: KEYS[1]=key; ARGV: budget, window_ms, now_ms → {allowed, remaining, retry_after_ms}
```

## Invariants and Failure Semantics

- Denial ⇒ caller maps to 429 at edge; limiter never knows HTTP.
- Window is fixed; burst bounded by budget; clock from caller (testable).
- Context cancel aborts Lua eval.
