## Objective

Install and enforce Uber's interprocedural nil-safety analyzer (`go.uber.org/nilaway`, installed via `@latest` like the other developer CLI tools) via `scripts/dev/setup.sh`, `Makefile` (`make nilaway` integrated into `make lint`), and `.github/workflows/ci.yml`, and remediate all static nil-flow findings across `./internal/... ./pkg/... ./cmd/...`.

## Scope

### In Scope

- `scripts/dev/setup.sh`: add `"nilaway:go.uber.org/nilaway/cmd/nilaway@latest"` to `GO_TOOLS`.
- `Makefile`: add `nilaway` target (`nilaway -include-pkgs="github.com/kadekutama/go-template" -test=false ./internal/... ./pkg/... ./cmd/...`) and wire it into `make lint`.
- `.github/workflows/ci.yml`: ensure `nilaway` is installed and executed in the lint pipeline stage.
- Remediate any nil-dereference risk reported by `nilaway` across `./internal/... ./pkg/... ./cmd/...` (such as unguarded map/slice indexing, nil struct pointer returns on error paths, or unchecked interface assertions).
- `SPEC.md §2` & `§11.1` updates.

### Out of Scope

- Running `nilaway` as a `golangci-lint` plugin (intentionally run via standalone `go/analysis` binary `nilaway` with `-include-pkgs` and `-test=false` to bound memory usage and avoid false positives on table-test mocks).
- `samber/lo` (`E09.2-T01`), `fxtest` (`E09.2-T02`), and `pyroscope-go` (`E09.2-T04`).

## Invariants and Failure Semantics

- **Zero Panic Budget (`SPEC.md §9.7`)**: Production code must never panic on nil pointer dereferences; functions must either return a valid non-nil pointer when `err == nil` or guard optional pointers before dereferencing.
- Do not suppress `nilaway` via blanket package exclusions on production code.
