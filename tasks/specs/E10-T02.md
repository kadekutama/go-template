## Objective

Ship a reviewable exchangerate.host-compatible FX rate adapter behind the
existing `port.FxRateProvider`, with fixed-point cache freshness, a visible
last-known stale rate during transient provider or egress unavailability,
single-flight coalescing for identical cache-miss pairs, and one E09.1-T03
egress permit per actual provider attempt — without committing the repository
to a production FX vendor (the FX source/freshness ADR remains owner-pending in
`docs/fintech-ledger-features.md`).

## Interfaces and Data

### Port amendment (doc comment only)

```go
// FxRateProvider fetches fixed-point conversion rates. Rates are fetched
// facts: staleness (TTL) is enforced by callers through IsStale, and floats
// never cross this boundary. GetRate returns the freshest rate the adapter
// holds: a cache-fresh rate, or a newly fetched one. When the provider or its
// egress path is unavailable, GetRate MAY return the last-known rate whose
// QuotedAt/TTL make IsStale(at) true; it MUST NOT hide that staleness behind a
// re-stamped timestamp. Callers MUST inspect IsStale before money movement
// (Convert rejects stale rates) and MUST NOT treat staleness as absence.
type FxRateProvider interface {
    // GetRate returns the freshest fixed-point rate for base→quote as of at.
    GetRate(ctx context.Context, base, quote valueobject.AssetCode, at time.Time) (valueobject.FxRate, error)
}
```

### Key builder (`internal/domain/service/fx_key.go`)

```go
func BuildFXRateKey(base, quote valueobject.AssetCode) (string, error) // "fx:{base}:{quote}"
func ParseFXRateKey(key string) (valueobject.AssetCode, valueobject.AssetCode, error)
```

- Reuses `validateKeySegment` (non-empty, ≤128 bytes, no `:`, no control
  characters) and returns `ISOLATION_KEY_INVALID` on violation, exactly like
  the existing E05-T03 builders.
- `ParseFXRateKey` requires the `fx:` prefix and exactly two segments; extra
  separators are rejected.
- The key is a cache/single-flight identity only, never an authorization
  decision.

### Adapter surface (`internal/infrastructure/fx`)

```go
type Params struct {
    BaseURL        string
    APIKey         string
    Source         string
    LivePath       string        // configured provider path, default "/live"
    HTTPClient     httpclient.Doer
    Cache          RateCache
    Egress         egress.Waiter
    Breaker        kernelres.Breaker
    Coalescer      Coalescer
    Clock          appport.Clock
    RetryPolicy    kernelres.RetryPolicy // explicit attempts/backoff, validated
    FetchTimeout   time.Duration // overall budget for one refresh loop
    MaxResponseBytes int64       // provider response cap
    MaxFutureSkew  time.Duration // allowed vendor clock skew
    MaxDecimalLen  int           // quote decimal length cap
    TTL            time.Duration // logical freshness, from cache.ttls.fx_sec
    StaleRetention time.Duration // physical cache retention, > TTL
    MaxQuoteAge    time.Duration // vendor timestamp sanity bound
}

type RateCache interface {
    Get(ctx context.Context, key string) (valueobject.FxRate, error)
    Set(ctx context.Context, key string, value valueobject.FxRate, ttl time.Duration) error
}

// Waiter is the shared egress-package contract; the concrete
// *egress.Limiter satisfies it.

type Coalescer interface {
    Do(ctx context.Context, key coalesce.Key, fn func(context.Context) ([]byte, error)) ([]byte, error)
}

func NewProvider(params Params) (*Provider, error)
func (p *Provider) GetRate(ctx context.Context, base, quote valueobject.AssetCode, at time.Time) (valueobject.FxRate, error)
```

- `*hybrid.TypedCache[valueobject.FxRate]` satisfies `RateCache`; the adapter
  does not import `hybrid` and never constructs cache layers.
- The coalesced work function serializes the rate with `pkg/jsonparser` because
  `Coalescer.Do` shares `[]byte`; the caller decodes it back to `FxRate`
  (no other codec is permitted).
- Constants owned by the adapter are only protocol/domain invariants:
  egress `provider=fx` / `operation=rates`, coalescing scope `global`, and
  rounding policy `half-up`. Runtime settings arrive through `Params` from
  config: `LivePath` (`fx.live_path`), `FetchTimeout`
  (`fx.fetch_timeout_sec`), `MaxResponseBytes` (`fx.max_response_bytes`),
  `MaxFutureSkew` (`fx.max_future_skew_sec`), and `MaxDecimalLen`
  (`fx.max_decimal_len`). The retry policy is an explicit `Params` seam
  (`{MaxAttempts: 3, InitialBackoff: 200ms, MaxBackoff: 2s, Multiplier: 2}` in
  production, validated with `RetryPolicy.Validate()`), so unit tests can use
  tiny backoffs without sleeping; E10-T01 established this `Params` pattern.
- `module.go` imports Uber fx as `uberfx` because the package itself is named
  `fx`; it provides `NewProvider` and binds it to `appport.FxRateProvider`.
- `config.go` owns the `Params`/interfaces, constructor validation, and the
  transport constants; `provider.go` owns the read/refresh/fallback path;
  `rates.go` owns pure JSON/decimal parsing; `err113_sentinel.go` owns the
  static sentinels.

### Cache value and quoting

- The cached value is the complete `valueobject.FxRate` (ID, pair, numerator,
  denominator, source, `QuotedAt`, `TTL`, rounding policy), so a stale fallback
  is byte-for-byte the last accepted fact.
- `QuotedAt` is the **observation instant** at which the adapter accepted the
  provider quote (fixed clock in tests). `TTL` is `cache.ttls.fx_sec`. This
  keeps `IsStale` equal to the documented "cache older than 1 hour" rule and
  lets the alert `ledger.fx.rate.age > 1h` describe refresh health.
- To keep that choice money-safe, the vendor `timestamp` is still validated:
  it MUST be positive, not more than 5 minutes in the future, and not older
  than `fx.max_quote_age_sec`; otherwise the response is rejected as
  `FX_INVALID_RESPONSE` and nothing is cached. A vendor serving decade-old
  data therefore fails closed instead of being re-stamped as fresh.
- The epic's "`stale:true` flag" is realized as `FxRate.IsStale(at)`: the
  accepted E03-T05 value object has no boolean stale field, and adding one
  would change that contract. Calling code gets the same information without
  a second source of truth.
- Requested pair: `valueobject.NewFxPair(base, quote)` (rejects empty/equal
  codes). Provider URL:
  `GET {BaseURL}/live?access_key={APIKey}&source={base}&currencies={quote}`.
  The response `source` MUST match `base` and `quotes` MUST contain
  `{base}{quote}` after upper-casing.

### Response shape parsed by `rates.go`

```json
{
  "success": true,
  "source": "USD",
  "quotes": {"USDEUR": 0.92},
  "timestamp": 1793136000
}
```

- `success:false` (with optional `error.type`/`error.info`) is a provider
  rejection; `error.info` is never echoed verbatim into a returned error.
- `quotes` values may be JSON numbers or numeric strings; `rates.go` decodes
  them as `jsonparser.Number` (the repository's alias for `json.Number`, the
  only stdlib JSON type imported outside the codec seam). `json.Number` accepts
  both a bare number and a valid numeric string, rejects a non-numeric string at
  decode time, and preserves the literal (including exponent and trailing-zero
  spellings) so `parseDecimal` can reject those spellings explicitly instead of
  silently normalizing them through a float. `json.RawMessage` was rejected
  because it defers the number/string distinction to hand-written byte handling
  and accepts any JSON token (including objects and booleans) at decode time.
  `big.Rat` parses the accepted decimal exactly and yields
  the reduced numerator/denominator; it reduces before the `int64` range check,
  which avoids a hand-written gcd/scale implementation and keeps
  `0.5000...`-style values within range when their unreduced denominator is
  not.
- `parseLiveRate(body []byte, base, quote valueobject.AssetCode, source string, now time.Time, policy parsePolicy) (valueobject.FxRate, error)`
  is pure and independently table-tested; `parsePolicy` carries `TTL`,
  `MaxQuoteAge`, `MaxFutureSkew`, and `MaxDecimalLen`. It assigns the
  deterministic ID `fx:{base}:{quote}:{now.UnixNano()}`, source from
  `Params.Source`, rounding policy `half-up`, and `QuotedAt = now`.

### Error codes (adapter-local, returned as `*entity.Error`)

| Code | Meaning | Retryable |
|------|---------|-----------|
| `FX_INVALID_CONFIG` | Missing/contradictory constructor params | no |
| `FX_PAIR_INVALID` | Empty or identical pair | no |
| `FX_INVALID_RESPONSE` | Undecodable/zero/overflowing/implausible quote payload | no |
| `FX_RATE_INVALID` | Parsed rate fails `FxRate.Validate()` | no |
| `FX_PROVIDER_UNAVAILABLE` | Transport error, 5xx, 429, breaker-open, retry exhaustion, no cache | caller policy |
| `FX_PROVIDER_REJECTED` | 4xx other than 429 (auth/request rejected) | no |
| `FX_EGRESS_UNAVAILABLE` | Egress denial/store failure with no cached rate | caller policy |
| `FX_RATE_UNAVAILABLE` | No rate exists for the requested pair | no |

## Invariants and Failure Semantics

- **Fixed point only.** Rates cross the port as reduced `int64` numerator and
  denominator. No float, `float64`, exponent, or fraction input reaches the
  arithmetic. Parsing uses `math/big.Rat` and rejects anything that does not fit
  the declared decimal grammar.
- **Staleness is visible, never invented.** A stale fallback returns the
  original `QuotedAt`/`TTL`; the adapter never rewrites them to appear fresh.
  A stale rate is returned with `nil` error so callers can render/decline it,
  and `service.Convert` still rejects it with `FX_RATE_STALE`.
- **Absence is not staleness.** If no cached rate exists and the upstream path
  is unavailable, the adapter returns a typed error and never a zero-value
  rate. No `(nil, nil)`-style contract; `GetRate` returns a value, not a
  pointer.
- **Quota is a hard boundary.** No code path may call `HTTPClient` without a
  successful `Egress.Wait` for that attempt. A denial or limiter-store failure
  ends the fetch attempt immediately; it never falls through to HTTP. Retries
  reacquire a permit. A pre-opened breaker short-circuits before any permit.
- **Breaker scope.** One breaker instance guards only provider HTTP calls
  (`Execute` wraps the single attempt after the permit). Egress/limiter errors
  occur outside the breaker and therefore never trip it. Breaker-open is
  terminal for the call (no retry storm, no extra permits).
- **Coalescing scope.** Only `provider=fx`, constant scope `global`, and the
  exact `fx:{base}:{quote}` digest coalesce. FX rates are public data with no
  tenant or credential context, so `global` is correct and must not be
  replaced by a caller identity. Results are shared only in flight; nothing is
  retained by the coalescer after completion.
- **Cache is a hint and a fallback, never authority.** A cache read error is
  treated as a miss; a cache write failure is best-effort and does not fail
  an otherwise valid fetch (the response is still returned, and the egress
  limiter bounds further traffic). Cache keys are not authorization decisions.
- **Time.** All freshness/expiry decisions use the injected `appport.Clock`;
  the `at` argument is the caller's valuation instant. A zero `at` resolves to
  the clock's current instant; a future `at` is clamped to now for freshness
  checks. The adapter does not serve historical series.
- **Privacy.** The API key is read from the environment variable named by
  config, never stored in `Config`, never logged, and removed from a sanitized
  copy of transport errors (the raw error, query string, key, and body are
  never returned or logged). Response bodies are size-capped and never echoed
  into errors; provider `error.info` is summarized, not copied.
- **Concurrency.** `Provider` is immutable after construction apart from the
  injected cache/breaker/clock state; it is safe for concurrent `GetRate`
  calls. The coalescer collapses identical in-flight misses; the cache write
  is idempotent (same value/TTL).
- **Retryability.** GET `/live` is idempotent: 5xx, 429, transport, and
  timeout errors retry within the explicit `Params.RetryPolicy` (3 attempts in
  production); 4xx (except 429), malformed payloads, invalid config/pair, and
  egress failures do not. Cancellation and deadline errors propagate unchanged
  and acquire no further permits.
- **Tenant boundary.** Rates carry no tenant data. The adapter neither reads
  nor propagates tenant identity; consumers apply tenant policy above it.

## Test Convention Exception (2026-10-28)

Per `AGENTS.md` Unit Test Structure §7 (return-value cardinality), the
cache-hit-no-work (`S01`), permit-per-attempt (`S05`, `S07`, `S15`), no-HTTP-on
denial (`S07`, `S08`, `S09`), single-flight (`S10`, `S11`), and cache-write-TTL
(`S02`) proofs require inspecting test-double internals (egress `Wait` call
count and exact `provider`/`operation`, `Doer.Do` call count, cache `Set` TTL,
breaker calls) alongside the function's return tuple. Those side effects cannot
be inferred from the returned `(FxRate, error)` pair: a fresh cache hit and a
provider refresh can return the same rate value, and a stale fallback and a
fresh fetch both return `nil`. For those scenarios only, each table case adds
one call-count/key/TTL assertion in addition to the exact return-arity
assertions. Two further proofs are also not inferable from the tuple because
the packet's verification plan demands them under `TestProvider`: the outbound
request shape (`TestProviderRequestShape` asserts the captured path and the
whole query map against `access_key`/`source`/`currencies`) for `R02`/`S02`,
and the redaction proof (`TestProviderErrorRedaction` asserts the returned
error contains `[REDACTED]` and never the key or base URL) for `R09`/`S21`.
Those three assertions are the complete additional set; all other scenarios
assert return arity exactly, with no implementation-detail or
test-double-internal checks. The integration suite repeats the same proofs
against real Valkey/HTTP/breaker components, where call counts are observable
behavior rather than mock internals. Every unit-test double is a mockery-generated
mock: `test/mock/fx` (`RateCache`, `Coalescer`), `test/mock/egress` (`Waiter`),
`test/mock/httpclient` (`Doer`), `test/mock/resilience` (`Breaker`), and
`test/mock/application` (`Clock`). The permitted side-effect checks read those
generated mocks' recorded `Calls` (method name, arguments, count) and never a
hand-written stub. No hand-written fake or stub remains in the FX test tree.
The additive `pkg/jsonparser/json_test.go` tests follow the same table shape with
no conditional early returns: `TestNumberDecodesNumberAndNumericString` asserts
the decoded out-parameter once and the returned error once per success case, and
`TestNumberRejectsNonNumericString` asserts only the returned error, which is
the function's sole return value.
