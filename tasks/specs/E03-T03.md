# Task Specification: E03-T03 — Payout domain rules (methods, states, settlement tracking)

**Task:** E03-T03
**Spec Status:** ready
**Author:** opencode-agent
**Reviewer:** repo-owner
**Last Updated:** 2026-09-14

## Objective

Ship pure payout rules: method registry with settlement lags, PENDING → IN_TRANSIT → PAID/FAILED machine, settlement tracking, overdue detection, cancel policy.

## Scope

### In Scope

- `internal/domain/valueobject/payout_method.go`: ACH, RTP/FedNow, Wire, Check + expected lag per money-flow §5.
- `internal/domain/valueobject/payout_status.go`: PENDING, IN_TRANSIT, PAID, FAILED, CANCELED + transition table.
- `internal/domain/service/payout_service.go`: submission/settlement line construction, failure/return reversal, overdue rule, cancel policy, provider reference shape.

### Out of Scope

- Provider submission, persistence, holds (E07/E10); eligibility/reserves (E03-T11).

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T03` for the backlog boundary.
- `docs/ledger-core.md §6.3` (payout submission + settlement journals, failure reversal).
- `docs/money-flow.md §2.2, §5` (two-stage settlement, lag table), `docs/domain-events.md §3.6`.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T03-R01 | Each method MUST carry its expected settlement lag per money-flow §5 (ACH/RTP/Wire/Check). | must |
| E03-T03-R02 | State machine MUST be PENDING → IN_TRANSIT → PAID / FAILED; CANCELED only from PENDING. | must |
| E03-T03-R03 | Submission MUST construct DR Merchant Payable / CR Payouts Payable; settlement DR Payouts Payable / CR Bank Cash. | must |
| E03-T03-R04 | Failure/return MUST reverse submission and post fees separately. | must |
| E03-T03-R05 | Overdue rule MUST flag actual > expected + grace via pure function. | must |
| E03-T03-R06 | Cancel after IN_TRANSIT MUST fail. | must |
| E03-T03-R07 | New code MUST import only stdlib + `internal/domain/...`. | must |
| E03-T03-R08 | Settlement MUST reference the same rail as its submission; staged accounts MUST be pairwise distinct (journal no-ops rejected). | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E03-T03-S01 | PENDING payout | Cancel | pass, CANCELED |
| E03-T03-S02 | IN_TRANSIT payout | Cancel | failure, cancel rejected |
| E03-T03-S03 | actual > expected + grace | IsOverdue | true |
| E03-T03-S04 | Each method | ExpectedLag | matches §5 table |
| E03-T03-S05 | Submission ACH vs settlement Wire; identical staged accounts | ValidateSettlement / ValidateSubmission | `PAYOUT_SETTLEMENT_MISMATCH` / `PAYOUT_ACCOUNT_INVALID` |
