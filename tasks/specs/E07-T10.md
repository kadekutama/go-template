## Objective

Persist non-ledger state (workflows, tenancy, reconciliation, periods, reports, approvals, inbox, audit) in separately-migrated tables that reference — but can never mutate — immutable financial facts.

## Scope

### In Scope

- `versions/000003_workflow_tenancy_recon.up/down.sql`: tenants, transfer/payout/dispute/payment/refund workflows, scheduled/batch transfers, recon sources/match groups/breaks, periods, reports, approvals, inbox receipts, audit references.
- `postgres/models/workflow.go`: GORM rows + table pins.
- `postgres/repositories/workflow.go`: CRUD adapters for workflow/recon/period/report stores.
- Lifecycle/version rules per aggregate; tenant+ledger scope keys; retention/partition indexes.

### Out of Scope

- Ledger-core tables (E07-T01, 000001–000002).
- RLS policies (E07-T02, 000004) beyond scope columns.
- Handler/saga logic (E06 owns); seed content (E07-T04); backup (E07-T05).

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E07-T10-S01 | Core schema applied | 000003 up then down | Extended tables appear; roll back cleanly; core untouched |

## Interfaces and Data

```go
// WorkflowStore{Create/Get/UpdateStatus} for payment/refund/payout/dispute/scheduled/batch kinds

// PeriodStore{Open/Close/Reopen}, ReportStore{Create/Get}, ApprovalStore{Record}, InboxStore{Receipt}, AuditStore{AppendRef}
```

## Invariants and Failure Semantics

- Version-guarded transitions; stale writes fail without side effects.
- Tenant scope on every row; missing/mismatched tenant fails closed.
- Duplicate workflow IDs conflict; inbox receipts dedupe on (tenant, key).
- Rollback of 000003 never touches 000001–000002 tables.

## Change Surface

**Owns:** `migration/versions/000003_*.sql`, `postgres/models/workflow.go`, `postgres/repositories/workflow.go` + tests.
**Coordinates:** `internal/domain/entity` (tenant/recon/period shapes, read-only), migration numbers 000001–000002/000004 (untouched), E06-T12 ports (persist behind, no signature changes).
**Must Not Touch:** ledger-core tables/models, RLS, outbox relay, seed/backup, statuses outside E07-T10, Git remotes.
