## Objective

Complete the LGTMP observability stack by adding `grafana/pyroscope:2.4.0` to `deployments/docker/docker-compose.observability.yml`, provisioning Grafana's Pyroscope datasource and Tempo `tracesToProfiles` span-to-flamegraph linkage, and implementing a default-off, loopback-only (`127.0.0.1:6060`) `net/http/pprof` diagnostic HTTP server in `internal/infrastructure/profiling/pprof_server.go`.

## Scope

### In Scope

- `deployments/docker/docker-compose.observability.yml` & `deployments/observability/pyroscope/config.yaml`: add `pyroscope` service (`image: grafana/pyroscope:2.4.0`, port `4040:4040`, `/ready` healthcheck, `pyroscope_data` volume).
- `deployments/observability/grafana/datasources/datasources.yaml`: provision `grafana-pyroscope-datasource` and configure Tempo `tracesToProfiles` correlation.
- `internal/infrastructure/profiling/pprof_server.go` & `pprof_server_test.go`:
  - `PprofServerParams` + `NewPprofServer` (Parameter Object pattern).
  - Default-off (`observability.pprof.enabled: false`), loopback-only bind validation (`127.0.0.1` / `::1` / `localhost` only; rejects `0.0.0.0`, `::`, or non-loopback IPs).
  - Private `http.ServeMux` registering `net/http/pprof` handlers (`Index`, `Cmdline`, `Profile`, `Symbol`, `Trace`, and `Handler("heap")`, `Handler("goroutine")`, `Handler("mutex")`, `Handler("block")`, `Handler("allocs")`).
- Runtime configuration sync (`internal/infrastructure/config/config.go`, `config/config.yaml`, `config/schemas/config.json`) for `PprofConfig`.

### Out of Scope

- Mounting `/debug/pprof` on public REST (`Echo`), gRPC, GraphQL, or Traefik ingress routers (strictly forbidden per `ADR-027`).
- Offline `google/pprof` benchmark flamegraphs and `default.pgo` generation (`E19-T05`).

## Invariants and Failure Semantics

- **Loopback Isolation**: `net/http/pprof` must never be registered on `http.DefaultServeMux` via a blank `_ "net/http/pprof"` import in production binaries; always construct an explicit private `http.NewServeMux()` inside `PprofServer` bound to `127.0.0.1`.
