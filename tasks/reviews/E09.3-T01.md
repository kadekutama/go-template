## Findings

### R-01 — `fx.Replace` did not replace the logger interface (fixed)

**Severity:** Medium (would have violated R07 and opened a second file rotator
in production)
**Location:** `internal/shared/di/fxlifecycle.go`

`fx.Replace(logger)` uses the dynamic concrete type of the supplied value. Since
`logger` is a `log.Logger` interface holding `*zerologLogger`, it replaced only
the concrete type and left `ProvideLoggerWithConfig` active. The fix annotates
the value as the interface. `TestRunAppReusesEntrypointLoggerInGraph` deliberately
leaves `APP_LOG_LEVEL` unset; with the old form the graph invokes the
config/logger provider and returns exit code `1`, while the annotated form
returns `0`. The old form was temporarily restored during review and the test
failed as expected; the fix was then restored and the focused suite passed.
**Status:** fixed.

### R-02 — Zero maximum size was accepted for file/both output (fixed)

**Severity:** Low (would silently fall back to lumberjack's default size instead
of failing fast on an explicit zero)
**Location:** `internal/infrastructure/logging/config.go`

`Config.Validate` now rejects `MaxSizeMB == 0` for `file`/`both`, while a zero
`MaxBackups`/`MaxAgeDays` remains unlimited retention. Added cases in
`TestConfigValidateOutputModes`, `TestNewFromConfig`, and
`TestProvideLoggingConfigEnvironment`.
**Status:** fixed.

### R-03 — Default parallel NATS startup failure (environmental; accepted)

**Severity:** Informational (not a code finding in this task's surface)
**Location:** `test/integration/messaging` test containers

The default `go test -v -race -count=1 ./...`, the CI-equivalent
`go test -race -count=1 ./...`, and the default
`./tasks/scripts/gate-check.sh G4` runs intermittently report
`nats: connect: nats: no servers available for connection` for
`TestNATSFanout` and/or `TestPublisherPublishEventValidation` on the local
Rancher Desktop/WSL Docker engine. The failing test shifts between reruns; all
other packages pass. The same messaging package passes in isolation, and the
full suite plus G4 pass with `GOFLAGS=-p=1`. No NATS, messaging, or
testcontainers file was modified. The owner confirmed CI and other-harness
integration runs are green and accepted this local testcontainers
readiness caveat for closeout on 2026-10-22. The serialized evidence is in
`tasks/evidence/E09.3-T01.md`.
**Status:** accepted by the repository owner (2026-10-22) as a local
environment/test-harness limitation; not an implementation defect and no
E09.3 action required.
