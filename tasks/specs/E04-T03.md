## Objective

Ship pure period-close gate rules: all four close blockers reported together, balanced closing entries, privileged reopen, and next-open-period late corrections.

## Scope

### In Scope

- `internal/domain/service/period_close.go`: `ValidateClose`, `BuildClosingEntries`, `ValidateReopen`, `ValidateLateCorrection`.

### Out of Scope

- Period persistence/scheduling (E07/E14); report rendering (E06/E18); handlers/API (E06/E11).

## Normative Inputs

- `tasks/epics/E04-compliance.md#E04-T03` for the backlog boundary.
- `docs/ledger-core.md §3.4` (effective_at must fall in an open period; recorded_at server-assigned).
- `docs/user-journeys.md §2.6` (close gate: no unresolved workflows, breaks resolved/acknowledged, sub-ledgers balanced, FX revalued).
- `docs/domain-events.md §3.8` (`period.opened/closed/reopened`).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E04-T03-R01 | `ValidateClose` MUST require an open period (`PERIOD_CLOSED` otherwise), reject negative counts (`CLOSE_INPUT_INVALID`), and return one error per failing gate check (unresolved workflows, open breaks, sub-ledger deltas, FX not revalued) — all reported, never first-only. | must |
| E04-T03-R02 | Closing entries MUST always balance per asset (income summary → retained earnings) by construction (`CLOSING_UNBALANCED` if inputs violate). | must |
| E04-T03-R03 | Reopen MUST require maker-checker (maker ≠ checker) plus reason (`SELF_APPROVAL_FORBIDDEN` / `REOPEN_REASON_REQUIRED` otherwise). | must |
| E04-T03-R04 | Late corrections to a closed period MUST target the next open period and retain original effective-date context (`LATE_CORRECTION_PERIOD_REQUIRED` otherwise). | must |
| E04-T03-R05 | All decisions MUST use explicit time/period params, no hidden clock. | must |
| E04-T03-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Executable Scenarios

## Invariants and Failure Semantics

- Close never mutates history; closing entries are new balanced facts in the closing period. Stable codes: `WORKFLOWS_PENDING`, `BREAKS_OPEN`, `SUBLEDGERS_UNBALANCED`, `FX_NOT_REVALUED`, `SELF_APPROVAL_FORBIDDEN`, `REOPEN_REASON_REQUIRED`, `LATE_CORRECTION_PERIOD_REQUIRED`, `CLOSING_UNBALANCED`.
- Empty deltas map means balanced; nil vs empty handled identically.
