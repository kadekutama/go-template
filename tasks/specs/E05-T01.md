# Task Specification: E05-T01 — Tenant aggregate + onboarding rules

**Task:** E05-T01
**Spec Status:** ready
**Author:** opencode-agent
**Reviewer:** repo-owner

## Objective

Ship the pure Tenant aggregate and deterministic onboarding checklist: validated tenant → default operating/fee/suspense accounts per asset → API key descriptor → `tenant.created.v1`, all-or-nothing at the domain level.

## Scope

### In Scope

- `internal/domain/entity/tenant.go`: `TenantStatus` (ACTIVE/SUSPENDED/CLOSED), `TenantSettings`, `TenantData` + `Validate()`.
- `internal/domain/aggregate/tenant.go`: `Tenant` root with `OpenTenant`, `Suspend`, `Reactivate`, `Close`, `UpdateSettings`; emits `tenant.created.v1` plus `tenant.updated/suspended/reactivated/closed.v1`.
- `internal/domain/event/tenant.go`: new `tenant.updated/suspended/reactivated/closed.v1` constructors (existing `tenant.created.v1` in `event/account.go` reused, not redefined).
- `internal/domain/service/tenant_onboarding.go`: `ValidateOnboarding`, `DefaultAccountsForAssets`, `IsRegionAllowed`, name-uniqueness check; all-or-nothing plan.
- `internal/domain/specification/tenant.go`: `TenantNameValid`, `TenantRegionAllowed`, `TenantSettingsValid` executable specs.

### Out of Scope

- Persistence, RLS, migrations (E07); handlers/ports (E06); API keys issuance/crypto (E09); hierarchy grants (E05-T02); cache/subject builders (E05-T03).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E05-T01-R01 | Tenant MUST carry non-empty ID, name (3–64 chars, no control chars), region (alphanumeric/hyphens, non-empty, no whitespace), status ACTIVE/SUSPENDED/CLOSED, settings with default currency + timezone, version ≥1, and non-zero UTC timestamps; `Validate()` MUST reject violations with stable codes (`TENANT_ID_REQUIRED`, `TENANT_NAME_REQUIRED`, `TENANT_NAME_INVALID`, `TENANT_REGION_REQUIRED`, `TENANT_REGION_INVALID`, `TENANT_STATUS_INVALID`, `TENANT_SETTINGS_INVALID`, `TENANT_VERSION_INVALID`, `TENANT_TIME_REQUIRED`). | must |
| E05-T01-R02 | Region MUST be checked against an explicit caller-supplied allowlist (`IsRegionAllowed`); disallowed/empty regions MUST fail `TENANT_REGION_INVALID`/`TENANT_REGION_REQUIRED`. Name uniqueness MUST be checked against a caller-supplied existing-name set (case-insensitive, trimmed); duplicates MUST fail `TENANT_NAME_DUPLICATE`. | must |
| E05-T01-R03 | Onboarding MUST be all-or-nothing: `ValidateOnboarding` returns a complete `OnboardingPlan` (tenant + default accounts + API key descriptor + ledger scope) or an error with no partial plan. Default accounts MUST be exactly operating + fee + suspense per requested asset (purpose/class/number deterministic). The requested assets MUST include the tenant settings default currency (`TENANT_SETTINGS_INVALID`), and asset codes MUST be non-empty, trimmed, and unique (`ASSET_CODE_INVALID`, `ASSET_CODE_DUPLICATE`, max 8 assets per call). | must |
| E05-T01-R04 | Aggregate lifecycle MUST enforce ACTIVE→SUSPENDED→ACTIVE, ACTIVE→CLOSED, SUSPENDED→CLOSED; CLOSED MUST be terminal. Illegal transitions MUST return coded errors (`TENANT_ALREADY_SUSPENDED`, `TENANT_NOT_SUSPENDED`, `TENANT_CLOSED`) and never panic. Every aggregate command (`OpenTenant`, `Suspend`, `Reactivate`, `Close`, `UpdateSettings`) MUST validate non-empty event metadata (`EVENT_ID_REQUIRED`), non-zero timestamps (`OCCURRED_AT_REQUIRED`), non-empty actor (`ACTOR_REQUIRED`), non-empty ledger (`LEDGER_REQUIRED`), and non-empty reasons (`TENANT_REASON_REQUIRED`). Domain events MUST be constructed before modifying state to ensure mutation atomicity on failure. | must |
| E05-T01-R05 | `TenantNameValid`, `TenantRegionAllowed`, `TenantSettingsValid` specs MUST be executable, stateless, and safe for concurrent reuse, returning stable violation codes. | must |
| E05-T01-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Invariants and Failure Semantics

- Tenant identity comes from authenticated context, never an ordinary body field (ledger-core §2). Uniqueness is repository-enforced; domain checks the supplied set deterministically (trim + case-fold).
- CLOSED is terminal; SUSPENDED blocks provisioning-side use via application policy, not via posting mutation.
- Errors carry stable UPPER_SNAKE codes; panics forbidden. Metadata/slice maps defensively copied.
- API key descriptor carries IDs/prefix only; no secret material in domain.
