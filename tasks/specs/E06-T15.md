# Task Specification: E06-T15 — Remove entity pre-mint across flows

**Task:** E06-T15  
**Spec Status:** ready  
**Decision:** approved  
**Author:** muse-spark  
**Reviewer:** repository-owner  
**Last Updated:** 2026-09-18

## Objective

Complete the DB-generation conversion after E07.1-T06: handlers stop
pre-minting entity IDs (repositories return database-assigned identities),
aggregate/service constructors accept empty pre-persist IDs, and the full
test pyramid proves identical behavior with database-assigned identifiers.

## Scope

### In Scope

- Delete entity pre-mint `NewID` calls in `internal/application/command/**`
  (account, tenant, transfer, posting, payout, topup, dispute, report,
  compliance, export, payment, transaction, reconciliation flows); use
  repository-returned IDs downstream. Event IDs, idempotency keys, and
  non-persisted correlation keep using `IDGenerator`.
- Open aggregate constructors (`OpenAccount`, transfer posting builders,
  `ReversePosting` params, `OpenTenant`, period/journal builders) and domain
  service entry points to empty pre-persist IDs (validate-when-set, matching
  the entity `Validate` posture from E07.1-T06).
- Update aggregate/service unit tests: empty-ID construction succeeds;
  malformed-ID cases assert the new `*_INVALID` codes; replay/eligibility
  semantics unchanged.
- Keep `IDGenerator` port and its fx wiring (events/keys/correlation).

### Out of Scope

- Alias assignment rule and provider-key audit (owned by E06-T14).
- Schema, models, repositories, ports, mocks (owned by E07.1-T06).
- Domain value objects and non-ID business rules (untouched).
