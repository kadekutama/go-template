# Task Specification: E03-T05 — FX value objects, rates, and gain/loss rules

**Task:** E03-T05
**Spec Status:** ready
**Author:** opencode-agent
**Reviewer:** repo-owner
**Last Updated:** 2026-09-14

## Objective

Ship pure FX rules: fixed-point rates with staleness, integer-only conversion, gain/loss calc, independently balanced currency lots.

## Scope

### In Scope

- `internal/domain/valueobject/fx_pair.go`: `FxPair{Base, Quote}` validation.
- `internal/domain/valueobject/fx_rate.go`: `FxRate{ID, Pair, Numerator, Denominator, Source, QuotedAt, TTL, RoundingPolicy}` + staleness rule.
- `internal/domain/service/fx_service.go`: `Convert` (fixed-point, no float), `GainLoss(authorizeRate, settleRate, amount)`, linked-lots balance check.

### Out of Scope

- Rate fetching/providers (E10); persistence.

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T05` for the backlog boundary.
- `docs/ledger-core.md §4, §6.5` (fixed-point rates, float ban, two balanced lots + explicit gain/loss).
- `docs/money-flow.md §2.7`, `docs/domain-events.md §3.9` (`fx.rate.updated.v1` shape).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T05-R01 | FX rates MUST be fixed-point numerator/denominator with source, quote time, TTL, rounding policy; floats MUST NOT appear. | must |
| E03-T05-R02 | Stale rates (>TTL at use time) MUST be rejected (`FX_RATE_STALE`). | must |
| E03-T05-R03 | Conversion MUST be integer-only with declared rounding (half-up) and overflow rejection. | must |
| E03-T05-R04 | Gain/loss MUST have correct sign for both directions (authorize vs settle). | must |
| E03-T05-R05 | Linked currency lots MUST each balance independently; mixed lots MUST fail. | must |
| E03-T05-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E03-T05-S01 | Fresh rate, amount 10000 | Convert | deterministic minor-unit quote |
| E03-T05-S02 | Rate older than TTL | Convert | `FX_RATE_STALE` |
| E03-T05-S03 | authorize vs settle rates | GainLoss | correct sign both directions |
| E03-T05-S04 | EUR lot balanced + USD lot balanced | LotsBalance | pass; broken lot fails |
