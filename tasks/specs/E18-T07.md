  `tasks/reviews/_TEMPLATE.md` and the validator (metadata fields, all nine
  sections, per-task file title).

- Accept report review mode case-insensitively, matching packet parsing.

  Base/Head line, with governing SDD sentences.
- Add validator unit tests for each fix and keep existing coverage green.
- Update the task handbook and index/progress totals.

  artifacts; they stay frozen as history.
- Changing review verdict semantics, severity policy, or gate thresholds.
- Any implementation (non-test Go), migration, contract, or E09 change.
