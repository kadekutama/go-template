## Objective

Enforce per-tenant region pinning: a request for a region-pinned tenant never reads/writes outside its region pool.

## Scope

### In Scope

- `postgres/router.go`: region→pool registry, request-scope resolution from tenant residency pointer, fail-closed unknown regions, audit entry recording for data-movement proof.
- Adversarial tests with pool spies proving EU-pinned traffic never touches the US pool.

### Out of Scope

- Residency policy definition (E05-T03 owns pointers); replica lag (E07-T07); RLS (E07-T02).
- Actual multi-region provisioning (E17 owns manifests; this task owns client routing).

## Normative Inputs

- `tasks/epics/E07-persistence.md#E07-T08` for the backlog boundary.
- `tasks/epics/E05-tenancy.md#E05-T03` (region/db pointers enforced here).
- `docs/fintech-ledger-features.md §5` (residency).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E07-T08-R01 | The router MUST resolve the connection pool from the tenant's residency pointer at request scope. | must |
| E07-T08-R02 | Unknown/unconfigured regions MUST fail closed (error, never default-region fallback). | must |
| E07-T08-R03 | Residency decisions MUST be recorded in audit entries for data-movement proof. | must |
| E07-T08-R04 | The router MUST live inside the repository adapters' pool selection (no new port). | must |

## Executable Scenarios

| ID | Given | When | Then |

| E07-T08-S02 | Tenant with unknown region | Pool selection | Error; no pool returned |
| E07-T08-S03 | Tenant without residency config | Pool selection | Fail-closed error |
| E07-T08-S04 | Routed request | Audit recorded | Entry carries tenant, region, timestamp |

## Interfaces and Data

```go
// router.Registry{Register(region, pool)}; router.Resolve(tenant Residency) (pool, error)
```

## Invariants and Failure Semantics

- Fail-closed on every unknown: region, tenant, or pool misconfiguration.
- No silent fallback: the default region is never assumed.
- Audit recording failure does not block routing but is surfaced.

**Coordinates:** repositories (pool selection call site), E05-T03 residency pointers (read-only).
**Must Not Touch:** ledger-core models, migrations, RLS, outbox, seed/backup, statuses outside E07-T08, Git remotes.
