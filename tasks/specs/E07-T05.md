## Objective

Executable backup/restore/verify paths for PITR (RPO<5min) and retention: `pg_dump` + WAL pointer → object storage, restore to scratch, verify row counts/balances/immutability/checkpoints.

## Scope

### In Scope

- `scripts/db/{backup,restore,verify-restore}.sh`: custom-format dump + WAL pointer; scratch restore; verification (row counts, per-asset balance, posting immutability constraints, checkpoint/cursor recomputation).
- E18 runbook input (this task provides scripts; E18 documents RPO/RTO measurement).
- E17 wires the weekly CI schedule (this task provides the scripts).

### Out of Scope

- Server-side WAL archiving config (E17 manifests); application code changes (none).
- Actual S3 buckets (MinIO locally via harness; S3 in prod by env).

## Normative Inputs

- `tasks/epics/E07-persistence.md#E07-T05` for the backlog boundary.
- `docs/fintech-ledger-features.md §11.3` (PITR, RPO<5min), `docs/data-flow.md §7` (retention), `SPEC.md §12` (DR targets).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E07-T05-R01 | `backup.sh` MUST produce a custom-format dump + record the WAL archive pointer alongside object-storage upload (MinIO locally, S3 in prod via env). | must |
| E07-T05-R02 | `restore.sh` MUST restore to a scratch database (never the source) from dump + pointer. | must |
| E07-T05-R03 | `verify-restore.sh` MUST check row counts, per-asset double-entry sums, posting immutability constraints, and full checkpoint/cursor recomputation. | must |
| E07-T05-R04 | Scripts MUST fail loudly on missing tools/env and never delete the source database. | must |
| E07-T05-R05 | No port: ops scripts talk to Postgres/object storage directly and implement none. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E07-T05-S01 | Live database | `backup.sh` runs | Dump + WAL pointer artifacts exist; exit 0 |
| E07-T05-S02 | Backup artifacts | `restore.sh` + `verify-restore.sh` run | Scratch DB verifies: counts match, sums balance, constraints hold |
| E07-T05-S03 | Missing DATABASE_URL/tools | Any script runs | Loud failure, non-zero exit, no side effects |

## Interfaces and Data

```sh
scripts/db/backup.sh [BACKUP_DIR]        # -> $BACKUP_DIR/ledger-<ts>.dump + wal-pointer.json
scripts/db/restore.sh <dump> <scratch>   # restores into scratch DSN
scripts/db/verify-restore.sh <src> <dst> # exits 0 only when all checks pass
```

## Invariants and Failure Semantics

- Source database is never written by these scripts (restore targets scratch only).
- Verification is read-only on both ends.
- Partial artifacts fail verification (checksums recorded at backup).
