## Objective

Deliver the hybrid read-model cache behind `port.Cache`: Otter v2.3.0 L1 + Valkey 9.1.2 L2 with post-commit invalidation and per-kind TTLs, usable with zero vendor credentials via fakes.

## Scope

### In Scope

- `internal/infrastructure/cache/local/otter.go`: Otter v2.3.0 generics cache (W-TinyLFU, per-key TTL, cost bound, sync visibility).
- `internal/infrastructure/cache/valkey/client.go`: go-redis v9.22.0 client (pool sizing, timeouts, optional TLS, Sentinel/Cluster compat).
- `internal/infrastructure/cache/hybrid/cache.go`: L1→L2→loader fallback, populate on miss, invalidate both layers only after DB commit; implements `port.Cache`.
- Key builders from `E05-T03` only; per-kind TTLs (balances 1m/5m cursor, configs 5m/30m, FX 1h, idempotency hints 24h, rate-limit 1m).
- Unit + Valkey Testcontainers coverage.

### Out of Scope

- Redlock (E08-T02), rate limiter Lua (E08-T07), broker topology (E08-T03+), provider/auth adapters (E09/E10), REST wiring (E11).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E08-T01-R01 | The hybrid MUST expose a typed API (`TypedCache[V].Get(ctx,key) (V,error)`, `Set(ctx,key,value V,ttl)`) over a shared bytes store; conversion happens once per L2 crossing through the single engine-wide `Codec`, and `Set` MUST be synchronously visible to the next `Get`. | must |
| E08-T01-R02 | The Valkey adapter MUST use go-redis v9.22.0 with configurable pool/timeouts/TLS and MUST work against Valkey 9.1.2 Sentinel and Cluster; its `Get`/`Set`/`Delete` MUST share the seam shapes with the Otter L1, and `TTL` MUST report the remaining TTL (persisted keys map to `store.NoExpiry`). | must |
| E08-T01-R03 | The hybrid MUST try L1→L2→miss, returning bytes from L1 (`Typed` views decode once per hit); it MUST populate L1 on an L2 hit with `min(configured L1Populate, remaining L2 TTL)` so an L1 copy never outlives the L2 record, and MUST reject non-positive TTLs on `Set`. | must |
| E08-T01-R04 | Invalidation MUST delete L2 first, then L1: the remote failable delete gates the local delete, so a failed L2 delete leaves L1 untouched and the caller can retry. `Delete` runs only after the authoritative DB commit; cache values MUST NEVER authorize spending or establish uniqueness. | must |
| E08-T01-R05 | All keys MUST come from `E05-T03` builders; callers MUST NOT hand-concatenate `balance:`/`idempotency:`/`ratelimit:` prefixes. | must |
| E08-T01-R06 | The adapter MUST implement `port.Cache` exactly and MUST NOT add provider-specific methods or HTTP semantics; a degraded L2 MUST fail open as a miss for reads. | must |
| E08-T01-R07 | Constructor params MUST be validated with `go-playground/validator` tags through the shared `validate.Struct` helper (all violations joined); nil-dependency rules stay explicit sentinel errors. | must |
| E08-T01-R09 | `Set` MUST reject non-cacheable Go kinds (func/chan/unsafe pointer/complex) up front with `ErrUnsupportedValueType`, while nil values of nil-able V stay legal: negative caching (storing "record does not exist") is supported so lookups do not stampede the database. Callers distinguish a negative entry from a miss by the returned error. | must |
| E08-T01-R10 | The cache MUST be shaped as one shared engine plus pure typed views: `Cache` (non-generic) owns the L1 bytes and the single L2 client and satisfies `port.Cache` directly; `hybrid.Typed[V](engine)` binds a `TypedCache[V]` view with zero construction. `New` receives the already-built, already-shared L1/L2 instances (one Otter, one Valkey pool) and never constructs adapters. Callers import only this package. | must |
| E08-T01-R08 | Every TTL MUST come from configuration (`CacheTTLsConfig.HybridTTLs()` → `TTLSet`); contract defaults stay unexported and reachable only through `DefaultTTLs()`, so no caller hardcodes a TTL constant. Zero config keeps defaults, negative config is an error. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E08-T01-S01 | Empty hybrid cache | `Get` missing key | `ErrCacheMiss`; nothing written |
| E08-T01-S02 | Value in L2 only | `Get` | L2 read, L1 populated bounded by remaining TTL; next `Get` is an L1 hit without an L2 read (`Typed` views decode once per hit) |
| E08-T01-S03 | L2 record already expiring | `Get` | Not copied into L1 (a copy never outlives its source) |
| E08-T01-S04 | Committed value then DB write | `Delete` after commit | L2 delete then L1 delete; both layers miss afterwards (stale-read test) |
| E08-T01-S05 | L2 delete fails | `Delete` | Error returned, L1 untouched (next Get cannot repopulate from stale L2) |
| E08-T01-S06 | L2 unreachable | `Get` | Fail-open miss wrapping `ErrCacheMiss` |
| E08-T01-S07 | Zero/negative TTL, empty key, or nil value | `Set` | Rejected with the typed sentinel error, no write |
| E08-T01-S08 | Invalid constructor params (blank addr, bad pool/timeouts) | Constructor | All validator violations joined into one error; nil seams rejected |
| E08-T01-S09 | Typed view with a structured V | `Set` then `Get` | Shared bytes store holds encoded bytes; `Get` returns `V` decoded once per hit |
| E08-T01-S10 | Partial/negative `CacheTTLsConfig` | `HybridTTLs()` | Zeros fill contract defaults via `WithDefaults`; a negative value returns an error |
| E08-T01-S11 | Negative cache entry (nil value) | `Set(ctx,key,nil,ttl)` then `Get` | Stored and returned with nil error (a hit, not `ErrCacheMiss`); expires normally |
| E08-T01-S12 | Non-cacheable V (func/chan/complex) | `Set` | `ErrUnsupportedValueType`, nothing written |
| E08-T01-S13 | Wiring with L2 nil | `New(Params{L1})` | L1-only engine built; `Engine` interface and port conformance hold |
| E08-T01-S14 | fx container with `Params` provided | `hybrid.Module()` | `fx.ValidateApp` passes and `port.Cache` resolves |
| E08-T01-S15 | Engine + two typed views | `hybrid.Typed[V]` twice | Both views share the engine's L1/L2 instances (one pool); pure view binding, zero resources |

```go

```

## Invariants and Failure Semantics

- Cached balances are labeled projections with cursor/as-of; spend/eligibility/idempotency read the strong projection.
- `Get` miss is a decision, never a panic; context cancellation aborts L2 I/O.
- An L1 entry copied from L2 never outlives the L2 record (bounded by remaining TTL); an already-expiring record is not copied.
- Delete order is L2→L1; a failed L2 delete surfaces and leaves L1 intact. Delete is post-commit invalidation, not a linearizable fence.
- Valkey down ⇒ `Get` returns a fail-open miss (wrapping `ErrCacheMiss`); `Set`/`Delete` surface the error (callers fail open for reads, fail closed for money at call site per port docs).
- No `redis.call` Lua in this task (only E08-T07 owns one script).
