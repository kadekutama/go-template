## Objective

Face the E03-T07 dispute domain to api-contracts §7.11: open/evidence/represent/close commands with deadline + second-representment guards, status/date-filtered queries, SoD passthrough, and §10-matching webhook facts.

## Scope

### In Scope

- `internal/application/port/usecase_dispute.go`: `DisputeUseCases` + command/query structs (missed by E06-T12's five contexts; added here with a T12 amendment note).
- `internal/application/command/dispute.go`: open (window + policy + hold ref), evidence (window + auto-mark-due), representment (versioned allowance), close-as-lost/won (SoD passthrough, status legality) with consumer-owned `DisputeStore`.
- `internal/application/query/dispute.go`: Get (with deadline + fee) / List (status/date filters) via delegation.
- `internal/application/dto/dispute.go`: edge shapes.
- Tests: post-deadline evidence rejected, second representment rejected, SoD violation, §10 payload fixtures.

### Out of Scope

- Representment provider filing (E10), dispute-fee settlement postings (E07 templates from domain lines), persistence schema (E07-T10 implements `DisputeStore`), early-warning auto-refund (policy input to E06-T04, not automation here).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E06-T11-R01 | Open MUST enforce the network window + versioned policy + hold reference; evidence after `EvidenceDueAt` MUST fail `EVIDENCE_WINDOW_EXPIRED`. | must |

## Invariants and Failure Semantics

- Domain owns windows, transitions, and allowances; the handler books stages and SoD gating around them.
- Evidence auto-marks OPEN→EVIDENCE_DUE before submitting (both domain transitions, one call).
- Unknown commit outcomes resolve via identical resubmission, never blind retry.
