## Objective

Ship authorization rules: hold-based authorize, partial-capture enforcement, idempotent expiry sweep, descriptor validation, SCA requires_action state.

## Scope

### In Scope

- `internal/domain/valueobject/auth_status.go`: AUTHORIZED, PARTIALLY_CAPTURED, CAPTURED, VOIDED, EXPIRED + transitions.
- `internal/domain/valueobject/descriptor.go`: ≤22 chars + network charset validation.
- `internal/domain/service/authorization_service.go`: Authorize (hold + expiry), Capture (CaptureAmountValid + single-vs-multiple policy), ExpirySweep (idempotent), SCA challenge states.

### Out of Scope

- Hold persistence, provider challenge completion (E07/E10-T03); handlers.

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T08` for the backlog boundary.
- `docs/money-flow.md §2.12`, `docs/domain-events.md §3.4` (`payment_intent.requires_action.v1`).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T08-R01 | Authorize MUST place a hold for the full amount with `auth_expires_at` (+7d default, network-configurable) and status AUTHORIZED. | must |
| E03-T08-R02 | Capture MUST enforce captured_total + capture ≤ authorized (`CAPTURE_EXCEEDS_AUTHORIZED` with remaining in details); single partial unless network allows multiples. | must |
| E03-T08-R03 | Expiry sweep MUST be idempotent (repeat produces one hold-release effect). | must |
| E03-T08-R04 | Descriptors MUST be ≤22 chars + network charset (`INVALID_DESCRIPTOR` otherwise). | must |
| E03-T08-R05 | SCA challenge MUST enter `requires_action`; resolution maps to succeeded/failed via E10-T03 completion shape. | must |
| E03-T08-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |
| E03-T08-R07 | Capture, challenge entry/resolution, and expiry sweep MUST honor the authorization transition table (`CanTransitionAuth`); capturing expired/voided/challenged auths or resolving non-challenged auths MUST fail. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E03-T08-S01 | Authorized 10000, captured 6000 | Capture 5000 | rejected with remaining 4000 |
| E03-T08-S02 | Expired auth swept twice | ExpirySweep | one release effect |
| E03-T08-S03 | Invalid descriptor | ValidateDescriptor | `INVALID_DESCRIPTOR` |
| E03-T08-S04 | SCA challenge | RequireAction → Resolve | requires_action then succeeded/failed |
