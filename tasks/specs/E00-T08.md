## Objective

Prove any harness can specify, claim, verify, hand off, and take over work
from repository state alone, with the validator rejecting every lifecycle
violation and CI enforcing the check.

## Scope

### In Scope

- Keep `tasks/SDD.md`, the four `tasks/*/_TEMPLATE.md`, `AGENTS.md`, and
  `.opencode/agents/*` harness-neutral (point at the protocol, no redefined
  rules).
- `tasks/scripts/test-sdd-lifecycle.py`: fixture lifecycle tests proving the
  validator accepts the valid cycle and rejects a dependency cycle, a missing
  packet, a duplicate/missing claim, a progress mismatch, and completion
  without evidence — all in a temporary tree, never touching real state.
- Wire `python3 tasks/scripts/check-tasks.py --format --graph --sdd` into the
  E00-T05 CI lint job (step, not a new job — the pipeline stays lint+build).

### Out of Scope

- Changing validator semantics (only exercised here).
- Full CI matrix (E17); content docs (E18).

## Normative Inputs

- `tasks/SDD.md §3, §4, §7` (lifecycle, takeover, required checks).
- `tasks/epics/E00-foundation.md#E00-T08` for acceptance criteria.
- `tasks/tracking/GATES.md#G1` (SDD metadata check row).
- `tasks/SDD.md` for evidence and completion rules.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E00-T08-R01 | A fresh agent MUST be able to identify the first runnable task and required context from repository files alone (`--ready` + packet + handoff chain unbroken). | must |
| E00-T08-R02 | Fixture tests MUST cover: valid full cycle accepted; dependency cycle rejected; active task without ready packet rejected; duplicate/missing claim rejected; PROGRESS mismatch rejected; completed task without evidence rejected. | must |
| E00-T08-R03 | `--format --graph --sdd` MUST pass on the real tree and MUST run in CI on every PR/push. | must |
| E00-T08-R04 | `AGENTS.md` and every `.opencode/agents/*.md` MUST link to `tasks/SDD.md` and MUST NOT redefine task status, evidence, or takeover rules. | must |

## Interfaces and Data

The validator CLI (`--ready`, `--format --graph --sdd`) is the interface
harnesses use for work selection. No code interfaces change.

## Invariants and Failure Semantics

- Fixture tests MUST run in a temporary directory and MUST NOT write to the
  real `tasks/` tree (assert real-tree `git status` clean afterwards).
- CI wiring adds a step to the existing lint job only — job names unchanged.

## Change Surface

**Owns:** `tasks/scripts/test-sdd-lifecycle.py`.  
**Coordinates:** `.github/workflows/ci.yml` (one added step; E00-T05/E17 own
the file), `AGENTS.md`/adapters (verify-only unless a violation is found).  
**Must Not Touch:** validator semantics, Go sources, task statuses other than
E00-T08, Git remotes.
