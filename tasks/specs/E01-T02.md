## Objective

Give every layer one `fx.Option` constructor and prove the composed graph has
no cycles, so all later binaries and tests wire through fx instead of globals.

## Scope

### In Scope

- `internal/shared/di/{domain,application,infrastructure,rest,grpc,graphql,cron,consumer}.go`,
  each exposing `XModule() fx.Option` (constructors, NOT package-level `var`,
  per the epic's grep acceptance check).
- `internal/shared/di/di_test.go` proving `fx.ValidateApp` passes over all modules.
- Minimal `cmd/*/main.go` composition (`fx.New(<module>, fx.NopLogger).Run()`).

### Out of Scope

- Real providers (E01-T04/T05 and later epics add `fx.Provide` calls with coordination notes).
- Real logger wiring (binaries use `fx.NopLogger` until E01-T04 lands).

## Normative Inputs

- `tasks/epics/E01-platform-core.md#E01-T02` for the backlog boundary.
- `SPEC.md §3.2` (dependency rule), `SPEC.md §8` (multi-binary).
- `tasks/SDD.md §3, §7` for packet, claim, evidence, and required checks.

## Interfaces and Data

`di.DomainModule()`, `ApplicationModule()`, `InfrastructureModule()`,
`RestModule()`, `GrpcModule()`, `GraphQLModule()`, `CronModule()`,
`ConsumerModule()` — each `func() fx.Option`. No other API.

## Invariants and Failure Semantics

- No `init()`, no globals, no import cycles (interface → application → domain
  direction preserved; di imports fx only).
- Later tasks add providers to these constructors with a coordination note; they
  MUST NOT introduce package-level state.
