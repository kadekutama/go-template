# Task Specification: E09-T02 — OAuth2/OIDC providers (Google, GitHub, generic)

**Task:** E09-T02
**Spec Status:** ready
**Author:** muse-spark
**Reviewer:** kadekutama
**Last Updated:** 2026-09-23

## Objective

Deliver federated login behind `port.OAuthProvider` with PKCE + signed `state`, provider mapping to internal identity, and no provider SDK types crossing the port.

## Scope

### In Scope

- `internal/infrastructure/auth/oauth2/` package: provider registry (google, github, generic OIDC discovery), `AuthURL`, `Exchange`, HMAC-signed `state` (10m TTL), PKCE S256, link table (in-memory + store seam).
- `Module() fx.Option` exposing `port.OAuthProvider`.
- Unit tests against `httptest` mock OIDC server (no vendor credentials).

### Out of Scope

- JWT minting details (E09-T01), RBAC decisions (E09-T03), user provisioning workflows (E06 handlers consume the identity).

## Normative Inputs

- `tasks/epics/E09-identity-security.md#E09-T02` for the backlog boundary.
- `SPEC.md §7.4` (federated login with PKCE) and `SPEC.md §2` (oauth2 v0.23.0).
- `internal/application/port/oauth.go` (`OAuthSession`, `OAuthIdentity`, `OAuthProvider` contract).
- `docs/development/go-conventions.md` (Params pattern, private fields, pointer receivers).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E09-T02-R01 | `AuthURL` MUST emit a provider URL with `state` (HMAC-signed, 10m TTL, tenant-bound) and PKCE `code_challenge=S256`. | must |
| E09-T02-R02 | `Exchange` MUST verify `state`, trade code single-use via the token endpoint, fetch userinfo, and MUST map to `OAuthIdentity`; replayed codes MUST fail. | must |
| E09-T02-R03 | Provider errors MUST map to `AppError`-style descriptive errors without leaking provider secrets or tokens. | must |
| E09-T02-R04 | No `golang.org/x/oauth2` SDK type may appear in the port signature or stored session. | must |
| E09-T02-R05 | The adapter MUST implement `port.OAuthProvider` exactly and MUST expose `Module() fx.Option`. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E09-T02-S01 | Registered provider + tenant | `AuthURL` | URL contains signed state + PKCE challenge; session stored short-lived |
| E09-T02-S02 | Valid code + state (mock OIDC) | `Exchange` | `OAuthIdentity` with provider user + email, code marked spent |
| E09-T02-S03 | Tampered/expired state or replayed code | `Exchange` | Rejected with distinct errors |
| E09-T02-S04 | Canceled context | `AuthURL`/`Exchange` | Context error, no side effects |

## Invariants and Failure Semantics

- Sessions expire quickly and bind to the requesting tenant; verifiers never leave the edge.
- Exchanges are single-use; unknown outcomes surface as errors for status resolution.
- Tokens expended at exchange are never stored by callers.
