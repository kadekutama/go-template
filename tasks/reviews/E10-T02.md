## Summary

It rigorously fulfills all 15 requirements (`E10-T02-R01`–`R15`) and 23 executable scenarios (`E10-T02-S01`–`S23`) defined in `tasks/specs/E10-T02.md`.

Key architectural and financial correctness highlights:
1. **Financial Precision:** Exact decimal-to-fraction parsing via `math/big.Rat` reducing quotes directly to lowest terms before `int64` bounds checking, completely eliminating floating-point arithmetic. Exponents, signs, fractions, leading zeros, and over-long payloads are strictly rejected by a compiled regular expression.
2. **Freshness & Visible Staleness:** Logical cache freshness (`cache.ttls.fx_sec`, 1h) is decoupled from physical retention (`fx.stale_retention_sec`, 24h). Fresh cache hits skip all upstream work; expired entries trigger background/inline refresh. During provider outages, egress throttling, or breaker trips, the last-known rate is returned unchanged with `nil` error, leaving `IsStale(at)` true for callers (`service.Convert`) to reject or inspect safely without silent fallback.
3. **Resilience & Quota Safety:** Every outbound HTTP attempt (including each retry) acquires exactly one `provider=fx, operation=rates` permit via `egress.Waiter`. Pre-opened circuit breakers fail closed before any egress permit or network call. Egress admission denials or limiter-store failures terminate attempts immediately without tripping the provider breaker.
4. **Single-Flight Coalescing:** Concurrent cache misses for identical pairs coalesce through `coalesce.CacheableFXRate` (`scope: global`), ensuring at most one upstream fetch, while distinct pairs remain strictly isolated.
5. **Configuration & Secrets:** All runtime settings (`live_path`, `fetch_timeout_sec`, `max_response_bytes`, `max_future_skew_sec`, `max_decimal_len`, `stale_retention_sec`, `max_quote_age_sec`) flow through `FXConfig` with schema-validated leaves; no Go constants shadow operational knobs. The provider API key is resolved from an uppercase environment variable name via `APIKey(lookup)` without storing secrets in configuration or logging them. Transport errors explicitly redact credentials via `[REDACTED]`.
6. **Test Uniformity & Double Hygiene:** Zero hand-written fakes or stubs ship in production code or test packages; every double is a Mockery-generated mock under `test/mock/**`. Unit tables strictly adhere to `AGENTS.md` table-driven conventions, with additional side-effect assertions covered by the explicit packet exception.

### CR-001 — Single-Use Fixture Variable Declared Outside Table Loop in `policy_test.go` [Low] [Confirmed]
- **Location:** `internal/infrastructure/fx/policy_test.go:20-21` — `TestFXPolicyFile`
- **Issue:** `data, err := os.ReadFile("../../../config/egress/fx.yaml")` and `require.NoError(t, err)` are declared before `testCases`. The variable `data` is only referenced in the first table case (`data: data`), while the second table case inlines its own YAML slice (`data: []byte("policies:\n...")`).
- **Why it matters:** Violates `AGENTS.md` Unit Test Structure and Scoping Policy Core Rule 3: *"No Single-Use Variables Declared Outside testCases: Inline all test-specific inputs directly inside each testCase. If deriving a variant from a base template, use an immediately-invoked anonymous closure."*
- **Evidence:** `internal/infrastructure/fx/policy_test.go:20-34`.
- **Plan violation:** `AGENTS.md` Unit Test Structure and Scoping Policy §3.
- **Expected behavior:** The file read should be inlined directly inside the first test case via an immediately-invoked closure:
  ```go
  data: func() []byte {
      d, err := os.ReadFile("../../../config/egress/fx.yaml")
      require.NoError(t, err)
      return d
  }(),
  ```
- **Recommended fix:** Move the `os.ReadFile` call and `require.NoError` into an inline anonymous closure within the first entry of `testCases`.
