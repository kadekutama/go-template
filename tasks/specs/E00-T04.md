## Objective

Fast `make dev-up` edit-rebuild loops for local development from E01 onward,
via air hot-reload plus compose wrapper scripts.

## Scope

### In Scope

- `.air.toml` (tracked base config) and `scripts/dev/dev-up.sh`,
  `scripts/dev/dev-down.sh`, `scripts/dev/dev-logs.sh` (executable, wired into
  the E00-T02 Makefile targets).

### Out of Scope

- Compose manifests themselves (E17 delivery); application code (later epics).
- `.air.toml.local` personal overrides (gitignored by E00-T01).

## Normative Inputs

- `tasks/epics/E00-foundation.md#E00-T04` for the air settings and script set.
- `SPEC.md §15` (dev workflows) and `README.md` (Quick Start) as consumers.
- `tasks/SDD.md` for evidence and completion rules.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E00-T04-R01 | `.air.toml` MUST watch `**/*.go` and `config/*.yaml`, exclude `bin/`, `vendor/`, `test/`, `docs/`, `.git/`, build `./cmd/rest-api`, and use a 500ms rebuild delay. | must |
| E00-T04-R02 | The three `scripts/dev/*.sh` MUST be executable, start/stop/tail the core compose set, accept passthrough args, use `set -euo pipefail`, and resolve the repo root relative to the script (no hardcoded paths). | must |
| E00-T04-R03 | The scripts MUST be wired into the `dev-up`/`dev-down`/`dev-logs` Makefile targets (already reference these exact paths — this task verifies the wiring resolves). | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E00-T04-S01 | The `.air.toml` file | It is parsed as TOML | Watch/include/exclude/cmd/delay match R01. |
| E00-T04-S02 | The three scripts | `bash -n` + executable-bit + Makefile-wiring checks run | Syntax valid, mode `+x`, wiring resolves. |
| E00-T04-S03 | An edit to a `cmd/rest-api` stub with air running | air detects the change | Rebuild + restart (deferred: needs air + Go toolchain; E00-T05 CI + dev machine). |

## Interfaces and Data

Scripts are the interface: `dev-up.sh [compose args]`, `dev-down.sh [args]`,
`dev-logs.sh [service]` passthrough to `docker compose` with the core file
set. No code interfaces change.

## Invariants and Failure Semantics

- Scripts fail fast (`set -euo pipefail`) and never swallow docker errors.
- No secrets or machine-specific paths in tracked files.

## Change Surface

**Owns:** `.air.toml`, `scripts/dev/dev-up.sh`, `scripts/dev/dev-down.sh`,
`scripts/dev/dev-logs.sh` (replaces the E00-T01 `.gitkeep` in `scripts/dev/`).  
**Coordinates:** `Makefile` dev targets (no change needed), E17 compose files.  
**Must Not Touch:** Go sources, task statuses other than E00-T04, Git remotes.
