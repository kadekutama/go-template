## Objective

Make report persistence the default reviewer outcome by replacing the
conditional persist-or-chat flow with a mandatory authorization checklist,
and by giving the agent an executable handoff-link step compatible with its
least-privilege permissions.

## Scope

### In Scope

- Add a persistence-default stance to the reviewer prompt's Mode section.
- Replace the conditional persistence paragraph with a numbered checklist:
  packet mode check, `Owns:` token check, active-claim check, write plus
  re-read confirmation, owner-ready handoff lines, and a burden-of-proof
  fallback that quotes the exact failed check.
- State explicitly that the reviewer cannot edit handoffs and must output
  the exact lines for the task owner instead of skipping linkage.
- Task index/progress totals.

### Out of Scope

- Frontmatter changes (E18-T09 design stands).
- Validator, template, or SDD text changes.
- Any implementation (non-test Go), migration, contract, or E09 change.
