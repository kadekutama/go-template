## Objective

Freeze the enforceable tenant-isolation contract E07/E08/E11 build against: deterministic cache-key builders, NATS subject builders, RLS policy matrix, residency + white-label shapes, and ADR-004 (shared DB + RLS).

## Scope

### In Scope

- `docs/architecture/ADR-004-tenant-isolation.md`: shared DB + RLS decision, consequences, E07 enforcement.
- `internal/domain/service/isolation.go`: balance/idempotency/rate-limit key builders + parsers, `BuildSubject`/`ParseSubject`, `RLSPolicyMatrix`, `ResidencySettings` + `Validate`, `WhiteLabelSettings` + `Validate`.

### Out of Scope

- RLS SQL/policies enforcement, repository tenant scoping (E07-T02); NATS topology/publishers (E08); REST tenant endpoints (E11); actual residency routing/DB pointers enforcement (E07).

## Normative Inputs

- `tasks/epics/E05-tenancy.md#E05-T03` for the backlog boundary.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E05-T03-R01 | Key builders MUST be deterministic and round-trip: `BuildBalanceKey` → `balance:{tenant}:{account}:{asset}`, `BuildBalanceCursorKey` → `balance:{tenant}:{account}:{asset}:{cursor}`, `BuildIdempotencyKey` → `idempotency:{tenant}:{operation}:{key}`, `BuildRateLimitKey` → `ratelimit:{tenant}:{user}`. Empty segments MUST fail (`ISOLATION_KEY_INVALID`); `Parse*` MUST invert `Build*` exactly. Colons inside segments MUST be rejected. | must |
| E05-T03-R02 | `BuildSubject(tenant, eventType)` MUST yield `ledger.{tenant}.{event_type}`; `ParseSubject` MUST invert it. Empty tenant/event, wrong prefix, or malformed shapes MUST fail (`ISOLATION_SUBJECT_INVALID`). Event type itself already contains domain/action segments and MUST NOT be re-scoped. | must |
| E05-T03-R03 | `RLSPolicyMatrix()` MUST cover every table in `docs/data-flow.md §5` core schema (tenants, asset_registry, ledgers, accounts, postings, entries, balance_checkpoints, holds, idempotency_records, outbox_events, inbox_receipts) with tenant×table×operation rows; global tables (asset_registry) MUST be marked shared-read. Missing-tenant context MUST be fail-closed (documented + tested helper `RequireTenant`). | must |
| E05-T03-R04 | `ResidencySettings{Region, DBPointer, ...}` MUST validate region allowlist + non-empty DB pointer (`RESIDENCY_*` codes). `WhiteLabelSettings{BrandName, Domains, ...}` MUST validate branding/domain formats (RFC hostname labels, no scheme/path, max lengths) with `WHITELABEL_*` codes and no behavior. | must |
| E05-T03-R05 | ADR-004 MUST record shared-DB + RLS (vs separate DB), consequences, and E07 enforcement pointer, and be linked from the architecture README index. | must |
| E05-T03-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Invariants and Failure Semantics

- Cache keys are hints only; durable DB key is `(tenant, operation, key)` (ledger-core §8). Subjects scope streams; versioned event type already contains domain/action.
- RLS matrix is a contract test input for E07-T02; this task writes the matrix, not the SQL.
- Stable codes: `ISOLATION_KEY_INVALID`, `ISOLATION_SUBJECT_INVALID`, `TENANT_REQUIRED`, `RESIDENCY_*`, `WHITELABEL_*`.
- Domain parsers never panic on malformed input.
