# Task Specification: E00-T07 — scripts/ Automation Package

**Task:** E00-T07  
**Spec Status:** ready  
**Author:** opencode-agent  
**Reviewer:** opencode-agent (self-review; low-risk tooling task per `tasks/SDD.md §3.1`)  
**Last Updated:** 2026-09-13

## Objective

Give every Makefile target a real executable behind it (and later epics their
assumed entry points) so no epic invents its own ad-hoc scripts.

## Scope

### In Scope

- 16 scripts: `scripts/build/build-all.sh`,
  `scripts/test/{unit,integration,contract,performance,chaos}.sh`,
  `scripts/generate/{mocks,gqlgen,proto,openapi}.sh`,
  `scripts/release/{changelog,tag,docker-push}.sh`,
  `scripts/security/{scan,sbom,licenses}.sh`.
  (`scripts/db/` belongs to E07-T05, `scripts/dev/` to E00-T04 — excluded.)
- Wiring: route `test-unit`/`test-all` through the new unit script so every
  script with a matching E00-T02 target is invoked by the Makefile.

### Out of Scope

- Tool implementations behind the scripts (mockery/buf/gqlgen/k6/litmus/syft
  arrive with their consumer epics); scripts fail loudly when their tool is
  absent.
- E17/E19 targets for performance/chaos/release/security scripts (no matching
  E00-T02 target exists; those epics wire them).

## Normative Inputs

- `tasks/epics/E00-foundation.md#E00-T07` for the script list and conventions.
- `SPEC.md §11` (pipeline) and `SPEC.md §15` (phases) as consumers.
- `Makefile` (E00-T02) for the wiring contract.
- `tasks/SDD.md` for evidence and completion rules.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E00-T07-R01 | All 16 scripts MUST exist, be executable, start with `set -euo pipefail`, print usage on `-h/--help`, pass extra args through, and resolve paths relative to the repo root (no hardcoded machine paths). | must |
| E00-T07-R02 | Every script whose tool is not yet vendored MUST fail with a clear "tool missing" message (never silent success, never partial output presented as success). | must |
| E00-T07-R03 | `test-unit`/`test-all` Makefile recipes MUST invoke `scripts/test/unit.sh` (and integration/contract scripts respectively); every E00-T02 script reference OWNED BY THIS TASK must resolve to an existing executable (`scripts/db/migrate.sh` is owned by E07-T05 and stays guarded-loud until then — see Open Questions resolution below). | must |
| E00-T07-R04 | `shellcheck` MUST be clean on all scripts once the tool exists (deferred to CI `make lint`; scripts are written to shellcheck-clean idioms). | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E00-T07-S01 | The scripts tree | Existence + `test -x` + `bash -n` + convention grep run | 16/16 pass. |

| E00-T07-S03 | A script whose tool is absent (e.g. `mocks.sh` without mockery) | It runs | Clear tool-missing error, non-zero exit. |

## Interfaces and Data

Script CLIs are the interface: `<script> [-h|--help] [passthrough...]`.
Stable paths are the contract later epics depend on. No code interfaces change.

## Invariants and Failure Semantics

- Fail fast; no partial-success masquerading.
- Scripts never write outside the repo root except via explicit tool behavior
  (docker, package managers) with args the caller supplied.

## Change Surface

**Owns:** the 16 scripts (replacing those dirs' `.gitkeep` files).  
**Coordinates:** `Makefile` `test-unit`/`test-all` recipes (minimal routing
edit; target list/names unchanged).  
**Must Not Touch:** Go sources, task statuses other than E00-T07, Git remotes.
