# Task Specification: E03-T07 — Dispute domain service (evidence, representment, fees)

**Task:** E03-T07
**Spec Status:** ready
**Author:** opencode-agent
**Reviewer:** repo-owner
**Last Updated:** 2026-09-14

## Objective

Ship dispute rules: network-window open with durable hold + fee posting, evidence window, versioned representment policy, close outcomes, fraud early-warning recommendation.

## Scope

### In Scope

- `internal/domain/valueobject/dispute_status.go`: OPEN, EVIDENCE_DUE, UNDER_REVIEW, WON, LOST, CLOSED + transitions.
- `internal/domain/entity/dispute.go`: `Dispute` record (network, opened/evidence-due timestamps, hold ref, fee ref, representment stage).
- `internal/domain/service/dispute_service.go`: OpenDispute, SubmitEvidence, CloseDispute, representment policy tables, early-warning rule.

### Out of Scope

- Hold persistence, provider representment filing (E07/E10); handlers (E06).

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T07` for the backlog boundary.
- `docs/money-flow.md §2.11`, `docs/fintech-ledger-features.md §3.3`, `docs/domain-events.md §3.12`.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T07-R01 | Open MUST reject disputes past the network window with distinct code (`DISPUTE_WINDOW_EXPIRED`). | must |
| E03-T07-R02 | Open MUST create a durable hold (not an entry) and post the dispute fee via approved template. | must |
| E03-T07-R03 | Late evidence MUST be rejected with distinct code (`EVIDENCE_WINDOW_EXPIRED`). | must |
| E03-T07-R04 | Representment stages/count/deadlines MUST come from versioned network policy fixtures, never hard-coded "exactly once". | must |
| E03-T07-R05 | Close MUST release/consume the hold and construct policy-approved postings; lost disputes produce balanced reversal entries linked to the original. | must |
| E03-T07-R06 | Fraud early-warning MUST recommend auto-refund when refund cost < expected dispute cost + fee. | must |
| E03-T07-R07 | New code MUST import only stdlib + `internal/domain/...`. | must |
| E03-T07-R08 | Every status change MUST flow through the transition table (`CanTransitionDispute`); evidence-due and sealed close use `MarkEvidenceDue` / `SealDispute` so all states are reachable and no transition is bypassed. | must |
