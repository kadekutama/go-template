# Task Specification: E01-T05 — Tracing port + OpenTelemetry SDK bootstrap

**Last Updated:** 2026-09-14

## Objective

Give middleware a backend-free `Tracer` port with W3C propagation helpers and a
working OTel SDK bootstrap (resource attrs, OTLP exporter, ratio sampling),
so E11/E12/E13 instrument uniformly.

## Scope

### In Scope

- `internal/shared/kernel/trace/{tracer.go,context.go}`: `Tracer`/`Span`
  interfaces (start, attributes, record error, end) + inject/extract helpers
  over a `MapCarrier` and an HTTP-header carrier. gRPC-metadata/NATS carriers
  compose the same propagator in E12/E14 (thin, transport-owned).
- `internal/infrastructure/tracing/{otel.go,config.go}`: `Bootstrap(cfg)`
  returning a `Provider` handle (TracerProvider + Shutdown); resource
  service.name/version/env; OTLP gRPC exporter when an endpoint is set;
  `ParentBased(TraceIDRatioBased)` sampling (default 0.1, configurable);
  `DefaultExcludedRoutes` for E11 health checks.
- New pin (recorded): `go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc v1.46.0`
  with the OTel family (core/trace/metric/sdk) at v1.46.0. Rationale recorded
  2026-09-14: the v1.40.0 exporter pin proved unbuildable — its graph pulls
  grpc v1.78+ whose chain selects trace v1.46.0, and trace v1.46.0 changed the
  `Span.RecordError` signature (ctx removed), which mixed minors cannot satisfy.
  Upward-only resolution to the consistent v1.46.0 family (2026-08-25 release);
  the kernel port drops the now-redundant ctx parameter to match upstream.

### Out of Scope

- Middleware itself (E11/E12/E13 consume the port).
- Tail-based error sampling (head sampling cannot see future errors; error
  spans always record status + events; E15 collector owns tail rules).
- Real OTLP backend (E15 owns the pipeline; tests use `tracetest` recorders).

## Requirements

| ID | Requirement | Priority |

| E01-T05-R01 | `Tracer`/`Span` MUST wrap OTel concepts without leaking the SDK into domain/app imports. | must |

| E01-T05-R05 | `Bootstrap` MUST return a `Shutdown(ctx)` that flushes spans; globals set by Bootstrap MUST be documented as the sanctioned OTel-standard exception. | must |

## Executable Scenarios

| E01-T05-S01 | SDK tracer (tracetest recorder) | Start→inject(MapCarrier)→extract | Same trace ID; span recorded. |

## Interfaces and Data

`trace.Tracer{Start}, trace.Span{End,SetAttributes,RecordError,SpanContext}`,
`trace.MapCarrier`, `trace.InjectHTTP/ExtractHTTP`, `tracing.Config{ServiceName,
ServiceVersion,Env,OTLPEndpoint,SampleRatio}`, `tracing.Bootstrap(cfg)
(*Provider, error)`, `Provider{Tracer(name),Shutdown,TracerProvider}`.

## Invariants and Failure Semantics

- Kernel imports OTel API (`go.opentelemetry.io/otel/trace`, `propagation`)
  only — never the SDK or exporters (adapter-only).
- Prod without endpoint fails closed; local without endpoint is explicit
  (documented), not silent: `Provider.exporting==false` is inspectable.
- Shutdown flushes with caller context; export failures surface, never panic.
