## Objective

G4 evidence for the persistence family: Testcontainers PostgreSQL 18 suites proving CRUD, migrations, RLS adversarial, outbox redelivery, idempotency replay, invariant attacks, concurrent-spend serialization, and fault-injection safety.

## Scope

### In Scope

- `test/integration/persistence/*_test.go`: per-repo CRUD, migration up/down/force, RLS adversarial, outbox atomicity/redelivery, idempotency replay/conflict, direct-SQL invariant attacks, concurrent-spend serialization with deterministic locks.
- Model-based concurrency: randomized operation sequences against the posting path must never produce negative available balance with overdraft disabled (ledger-core §11).
- Fault-injection matrix: crash before/after commit, publish-ack loss, inbox-commit failure, provider timeout → documented safe outcomes.
- Docker-gated: skip cleanly without a daemon; `-race -count=3` in CI with Docker.

### Out of Scope

- Feature code (all other E07 tasks own it); broker/consumer suites (E08-T06); provider suites (E10-T06).
- k6/chaos cross-cutting suites (E16 owns).

## Normative Inputs

- `tasks/epics/E07-persistence.md#E07-T06` for the backlog boundary.
- `docs/ledger-core.md §11` (concurrency proof requirement), `SPEC.md §10.3` (integration), `SPEC.md §12` (persistence targets).
- `tasks/specs/E07-T09.md` (harness this suite consumes).
