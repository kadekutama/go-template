## Objective

Build once the five artifacts every command handler repeats: generic command/query handler contracts, canonical idempotency fingerprint + run helper, domain-to-envelope error translation with locale rendering, and a fail-closed authorization helper.

## Scope

### In Scope

- `internal/application/command/handler.go`: generic `CommandHandler[C, R]` with ordinary `(R, error)` returns.
- `internal/application/query/handler.go`: generic `QueryHandler[Q, R]` with ordinary `(R, error)` returns.
- `internal/application/command/idempotency.go`: canonical `Fingerprint` (SHA-256 over length-prefixed parts), `MapParts` (order-independent map encoding), + `RunIdempotent` (reserve → replay-or-execute-once → complete) over `port.IdempotencyStore`.
- `internal/application/service/error.go`: `ToAppError` (domain `*entity.Error` → kernel `*apperror.AppError` via a documented code map, AppError passthrough, unknown → `INTERNAL_ERROR` with cause) + `Localize` (context-locale rendering via the kernel `Translator`).
- `internal/application/command/authz.go`: `Require` (fail-closed on empty subject identity, then delegate to `port.Authorizer`).
- Tests proving a sample `CreateAccount` handler uses all five artifacts with fakes, and that double-submit executes once.
- Removal of the superseded `internal/application/.gitkeep`.

### Out of Scope

- Concrete account/transfer/payment handlers (E06-T02–T05/T11/T13), sagas (E06-T07), DTOs, persistence (E07), and the Casbin adapter (E09 enforces; this task only calls the port).
- Canonical request fingerprint for HTTP bodies (edge mints fingerprints from its DTOs in E11; this task hashes caller-supplied parts).

## Interfaces and Data

```go
// CommandHandler[C, R]{Handle(ctx context.Context, cmd C) (R, error)}
// QueryHandler[Q, R]{Handle(ctx context.Context, query Q) (R, error)}
// Fingerprint(parts ...string) string
// RunIdempotent(ctx, store port.IdempotencyStore, rec port.IdempotencyRecord, execute func(ctx) ([]byte, error)) (response []byte, replayed bool, err error)
// ToAppError(err error) *apperror.AppError
// Localize(ctx context.Context, translator *apperror.Translator, err error) string
// Require(ctx, authz port.Authorizer, subject port.Subject, action, resource string) error
```

## Invariants and Failure Semantics

- Stages never swallow errors: replay returns the original bytes verbatim; conflicts and denials are errors, not flags.
- `RunIdempotent` does not retry execution itself; the uncompleted lease lets a later identical submission execute (at-most-once per completed fingerprint, not at-most-once delivery).
- Translation never blanks messages: unknown codes/locales fall back to the source message.
- No infrastructure, provider, or protocol imports in `internal/application/...` (stdlib + domain + own ports + shared kernel only).
