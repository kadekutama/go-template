## Objective

Close the shell-permission bypass identified in review of `.opencode/agents/implementer.md` by requiring owner approval for every shell invocation, including commands that appear read-only.

## Scope

### In Scope

- Remove shell-specific `allow` exceptions from `.opencode/agents/implementer.md` so the catch-all shell approval rule applies to every shell command.
- Restore the platform's secret-file read protection in `.opencode/agents/implementer.md` by appending `.env`-specific read rules after the broad read allow (amendment 2026-10-04T08:16:28Z, owner-approved).
- Update the Git-safety text to accurately describe the permission policy.
- Update the E18 backlog/index/progress records and this task's SDD artifacts.

### Out of Scope

- Changes to other agents, global OpenCode configuration, or permission behavior outside this profile. `.opencode/agents/reviewer.md` has the same `.env` read gap; its parity fix is deferred to a follow-up task and stays outside this claim's surface.
- Changes to any E09.1 planning or implementation files.
- Commits, pushes, branch changes, or broad repository test failure remediation.
