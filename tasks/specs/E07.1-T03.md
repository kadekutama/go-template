# Task Specification: E07.1-T03 — CloudNativePG (CNPG) Kubernetes deployment manifests

**Task:** E07.1-T03  
**Spec Status:** ready  
**Author:** muse-spark

**Last Updated:** 2026-09-17

## Objective

Provide declarative Kubernetes manifests for running Citus 14.0 on CloudNativePG v1.30.0 with native Kubernetes Lease HA, so the distributed persistence topology has a Kubernetes-native deployment profile alongside the Patroni compose profile.

## Scope

### In Scope

- `deployments/k8s/cloudnativepg/citus-coordinator.yaml`: CNPG Cluster CR for the Citus coordinator (3 replicas, Citus extension enabled, backup stanza).
- `deployments/k8s/cloudnativepg/citus-workers.yaml`: CNPG Cluster CRs for 2 Citus worker shards with automated backup config and post-init worker registration on the coordinator.
- `deployments/k8s/cloudnativepg/kustomization.yaml`: kustomize entrypoint wiring coordinator + workers with common labels, secrets references, and network policies.
- Service endpoints, connection secrets, and network policy declarations.

### Out of Scope

- Docker Compose Patroni topology (owned by E07.1-T02).
- Migration file contents and Goose runner (owned by E07.1-T01).
- etcd client adapter (owned by E07.1-T04).
- Go integration tests (owned by E07.1-T05).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E07.1-T03-R01 | The coordinator manifest MUST declare a CNPG Cluster CR with 3 instances, Citus extension in bootstrap initdb/post-init, and a named backup stanza. | must |
| E07.1-T03-R02 | The worker manifest MUST declare CNPG Cluster CRs for 2 worker shards with backup config and a post-init script registering each worker on the coordinator. | must |
| E07.1-T03-R03 | Manifests MUST declare Services, connection Secrets references, and NetworkPolicies restricting Postgres traffic to application and intra-cluster peers. | must |
| E07.1-T03-R04 | The kustomization MUST reference coordinator + worker resources with common labels and namespace defaults. | must |
| E07.1-T03-R05 | Manifests MUST pass client-side dry-run validation (`kubectl apply --dry-run=client -k`). | must |

## Interfaces and Data

- Kubernetes resources: CNPG `Cluster` CRs (`citus-coordinator`, `citus-worker1`, `citus-worker2`), `Service`, `Secret` references, `NetworkPolicy`.
- Kustomize entrypoint: `deployments/k8s/cloudnativepg/kustomization.yaml`.
- No application Go interfaces change in this task.

## Invariants and Failure Semantics

- **Declarative only**: manifests declare desired state; no imperative cluster mutation in this task.
- **Secret hygiene**: no plaintext passwords in manifests; only Secret references.
- **Citus linkage**: worker-to-coordinator registration is an explicit post-init step, never an implicit network side effect.
