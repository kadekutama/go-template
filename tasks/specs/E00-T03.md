## Objective

Enforce the SPEC §16 quality gate in CI from day one with a strict,
error-severity golangci-lint configuration.

## Scope

### In Scope

- `.golangci.yml` with the exact linter set from
  `tasks/epics/E00-foundation.md#E00-T03`, error severity, and the gocyclo
  threshold; referenced by `make lint` (E00-T02) and `ci.yml` (E00-T05).

### Out of Scope

- Fixing future lint findings in business code (each epic owns its own).
- Full CI matrix (E17); custom lint rules (none — stock linters only).

## Normative Inputs

- `tasks/epics/E00-foundation.md#E00-T03` for the linter list and thresholds.
- `SPEC.md §16` (per-phase gates: linting passes).
- `docs/development/go-conventions.md` for implementation conventions.
- `tasks/SDD.md` for evidence and completion rules.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E00-T03-R01 | `.golangci.yml` MUST enforce at minimum: `errcheck`, `govet`, `staticcheck`, `gosec`, `bodyclose`, `noctx`, `rowserrcheck`, `sqlclosecheck`, `goconst`, `gocritic`, `gocyclo`, `ineffassign`, `misspell`, `unconvert`, `unparam`, `unused` as linters plus `gofmt`/`goimports` as formatters (v2 schema separates the two sections; verified with the pinned binary). | must |
| E00-T03-R02 | Severity MUST be error (issues fail the run); `gocyclo` `min-complexity` MUST be `12`. | must |
| E00-T03-R03 | The config MUST be referenced by `make lint` (already: `golangci-lint run ./...`) and by `.github/workflows/ci.yml` (E00-T05 wires it; this task records the contract). | must |
| E00-T03-R04 | `golangci-lint run ./...` MUST pass on the empty tree once the tool exists. | must |
