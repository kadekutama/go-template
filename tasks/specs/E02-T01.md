## Objective

Ship the two domain primitives every later E02–E05 task consumes — the event envelope (`internal/domain/event/base.go`) and the stateless specification combinators (`internal/domain/specification/specification.go`) — stdlib-only, immutable, race-safe, with backlog acceptance proven by focused unit tests.

## Scope

### In Scope

- `internal/domain/event/base.go`: `DomainEvent` interface (superset of `SPEC.md §5.1` with `docs/domain-events.md §2.1` envelope), `EventMetadata{tenant,ledger,causation,correlation,user,trace,custom}`, `BaseEvent` immutable implementation with `AggregateVersion()`/`Sequence()` ordering accessors, validated constructors.
- `internal/domain/specification/specification.go`: `Specification[T]` with stateless `Evaluate`, `SpecResult{Violations}`, `Violation{Code,Message,Details}`, `All`/`Any`/`Not` combinators with defined empty/nil semantics.
- Focused unit tests for both packages (table + race + concurrent-reuse tests).
- Static guard proving no external imports in `internal/domain/...`.

### Out of Scope

- Concrete aggregate types and lifecycle methods (E02-T03–T05 own `Account`, `Posting`, `Hold`, `Journal`, `Period`).
- Typed event catalog payloads `account.created.v1` etc. (E02-T06 owns the catalog; this task ships only the envelope).
- Money-rule specs `SufficientFunds`, `PostingBalancesPerCurrency` etc. (E02-T07 owns the catalog).
- Repository ports (E02-T08), wire serialization and outbox publication (E08 adapter), webhook projections (API tasks).
- ID generation and clock implementations (E01-T06 kernel owns `IDGenerator`/`Clock`; domain accepts caller-supplied IDs and timestamps).

## Interfaces and Data

```go
// internal/domain/event/base.go (stdlib only: context-free, time, errors)
type EventMetadata struct {
    TenantID string; LedgerID string; CausationID string
    CorrelationID string; UserID string; TraceID string
    Custom map[string]string
}
type DomainEvent interface {
    EventID() string; AggregateID() string; AggregateType() string
    EventType() string; OccurredAt() time.Time
    AggregateVersion() int64; Sequence() int64
    Payload() any; Metadata() EventMetadata
}
// BaseEvent: unexported fields, value receivers, no mutators.
func NewBaseEvent(eventID, aggregateID, aggregateType, eventType string,
    occurredAt time.Time, aggregateVersion, sequence int64,
    payload any, meta EventMetadata) (BaseEvent, error)
```

```go
// internal/domain/specification/specification.go (stdlib only: context)
type Violation struct { Code string; Message string; Details map[string]string }
type SpecResult struct { Violations []Violation }
func (r SpecResult) Passed() bool
type Specification[T any] interface { Evaluate(ctx context.Context, candidate T) SpecResult }
func All[T any](specs ...Specification[T]) Specification[T]
func Any[T any](specs ...Specification[T]) Specification[T]
func Not[T any](spec Specification[T], violation Violation) Specification[T]
// Test helper owned here: NewFuncSpec(code, func(ctx, T) bool) for table tests.
```

- Conflict resolved (recorded, not silent): `SPEC.md §5.1` lists the narrow minimum (`EventID/AggregateID/EventType/OccurredAt/Payload`); the envelope implemented here is the `docs/domain-events.md §2.1` + `docs/ledger-core.md §9` superset adding `AggregateType`, `AggregateVersion`, `Sequence`, and `Metadata`. The narrow readers still compile against the interface; the full envelope is what the outbox (E08) serializes.
- Versioning: `EventType` strings are opaque to this task; format `<subject>.<action>.v<n>` is validated non-empty here and cataloged in E02-T06.
- Ownership: E02-T06 (event catalog) and E02-T07 (rule specs) consume these types; they MUST NOT redeclare competing `DomainEvent` or `Specification` interfaces.
- No wire, migration, or config change in this task.

## Invariants and Failure Semantics

- Ordering is defined by `(aggregate_version, sequence)`, never wall-clock timestamps (`docs/ledger-core.md §9`); this task exposes the accessors, aggregates assign monotonic values.
- `recorded_at` (server-assigned persistence timestamp) is NOT a domain field; E07 stamps it at commit.
- Domain never generates IDs or reads clocks: callers (application layer via kernel `IDGenerator`/`Clock`) supply `event_id` and `occurred_at`; domain validates and normalizes to UTC.
- Errors are ordinary Go `error` values from constructors; `Evaluate` reports rule failure as `Violation` data, not errors; panics are forbidden on all paths (constructors validate, specs nil-guard).
- `Violation.Code` is a stable UPPER_SNAKE token supplied by the spec author; the kernel `AppError` registry mapping happens in application/interface layers, not here.
- Security: `Custom` MUST NOT carry secrets, idempotency keys, or unrestricted PII; webhook allow-listing belongs to E08/API projection tasks.
- Tenant boundary: empty `tenant_id` is rejected; `ledger_id` is omitempty but MUST be propagated whenever the aggregate is ledger-scoped.
