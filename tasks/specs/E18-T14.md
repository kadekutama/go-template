## Objective

Keep repository agent guidance accurate across OpenCode and Antigravity 2 while making review persistence straightforward: any user-selected reviewer may create or edit Markdown files without packet/claim authorization, while reviewer profiles remain read-only for non-Markdown implementation changes. Preserve durable, attributed, append-only review contributions and allow multiple reviewers to contribute to the same task. Retain the broader task's hardened implementer/reviewer guidance, tool allowlists, docs, linter policy, and Go conventions.
