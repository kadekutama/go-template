# Task Specification: E07.1-T05 — Multi-node Citus integration test suite

**Task:** E07.1-T05  
**Spec Status:** ready  
**Author:** muse-spark  
**Reviewer:** repository-owner  
**Last Updated:** 2026-09-17

## Objective

Prove tenant sharding correctness and local ACID behavior on a multi-node Citus cluster via a Testcontainers-based integration suite, including Patroni-style failover data-integrity posture (synchronous replication, zero transaction loss).

## Scope

### In Scope

- `test/testcontainers/citus.go`: Testcontainers fixture booting a Citus coordinator + worker cluster with pinned images and bounded startup contexts.
- `test/integration/citus/citus_test.go`: tenant co-location (same-tenant entries/postings execute locally), cross-tenant aggregation (SUM balance across accounts), and synchronous-replication failover posture (zero transaction loss / bounded RPO) with Docker-gated skips when no daemon is reachable.
- Deterministic, isolated databases/streams per test with cleanup; race-detector clean.

### Out of Scope

- Compose topology YAML (owned by E07.1-T02).
- CNPG manifests (owned by E07.1-T03).
- Migration runner implementation (owned by E07.1-T01); this task consumes the migrated schema.
- etcd adapter behavior (owned by E07.1-T04).

- `docs/architecture/ADR-013-citus-sharding-and-flexible-ha.md` for tenant co-location and failover semantics.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E07.1-T05-R01 | The fixture MUST boot an isolated Citus coordinator + worker cluster via Testcontainers with pinned images and bounded contexts, skipping cleanly without a Docker daemon. | must |
| E07.1-T05-R02 | Tests MUST verify tenant co-location: same-tenant postings/entries route locally without distributed deadlock. Mechanism proof uses FK-free probe tables distributed on `tenant_id` (identical shard count/type ⇒ shared colocation group) plus distribution metadata; FK-constrained ledger tables take the migration's resilient path (per-table NOTICE) until composite-key redesign. | must |
| E07.1-T05-R03 | Tests MUST verify cross-tenant aggregation (SUM balance across all accounts) returns correct totals. | must |
| E07.1-T05-R04 | Tests MUST verify the synchronous-replication posture: with `synchronous_commit = on`, an ungraceful primary kill loses zero committed transactions (RPO=0); async posture documents bounded RPO < 1s. | must |
| E07.1-T05-R05 | Suites MUST run with `-race` and meet Gate G4 coverage expectations for the touched packages. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E07.1-T05-S01 | Citus fixture cluster | Tenant-A probe rows batch executes on tables sharing one colocation group | All rows land on the same worker shard (colocation metadata confirms); ledger-table distribution state is logged (resilient NOTICE path where FK topology blocks). |
| E07.1-T05-S02 | Two tenants with balances | Cross-tenant SUM aggregation runs | Totals equal the sum of per-tenant balances. |
| E07.1-T05-S03 | Synchronous standby replication | Primary killed ungracefully after commit ack | Promoted standby serves all committed rows with zero loss. |
| E07.1-T05-S04 | No Docker daemon | Suite executes with `TESTCONTAINERS_SKIP=1` or unreachable daemon | All tests skip (never fail). |

## Interfaces and Data

- Suite: `test/integration/citus/citus_test.go` consuming the fixture plus the `migration` runner.
- No production Go interfaces change in this task.

## Invariants and Failure Semantics

- **Isolation**: parallel packages use isolated databases; every test registers cleanup; no leaked containers.
- **Skip-not-fail**: without Docker the suite skips; with Docker it must be deterministic and race-clean.
- **Ledger safety**: co-location checks never weaken per-asset balance or immutability rules from `docs/ledger-core.md`.
