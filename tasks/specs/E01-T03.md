# Task Specification: E01-T03 — Layered configuration with validation (koanf)

**Task:** E01-T03  
**Spec Status:** ready  
**Author:** opencode-agent  
**Reviewer:** opencode-agent (self-review recorded per `tasks/SDD.md §3.1`; mechanical config plumbing, no financial/cryptographic/migration behavior)  
**Last Updated:** 2026-09-14

## Objective

Deliver one validated `Config` struct loaded base → env-file → local → env-vars
→ secrets, failing fast with every violation listed, so all later binaries share
a single configuration contract.

## Scope

### In Scope

- `internal/infrastructure/config/{config.go,loader.go}` + `loader_test.go` (+ schema-alignment test).
- `config/config.yaml`, `config.local.yaml.example` (sample; real `config.local.yaml`
  is gitignored and optional), `config.staging.yaml`, `config.production.yaml`,
  `config/schemas/config.json` (inline objects, no `$ref`, so tests can walk it).
- Companion pins (same `go get`, recorded): `knadh/koanf/providers/file v1.2.1`,
  `knadh/koanf/providers/env v1.1.0`, `knadh/koanf/parsers/yaml v1.1.1`,
  `knadh/koanf/parsers/json v1.0.1` (schema-alignment test input; keeps
  `encoding/json` out of our code ahead of the E01-T07 codec seam)
  (koanf/v2 core ships no providers/parsers; these are its decoupled companions).
- `scripts/config/validate.sh` + `make validate-config` (additive Makefile target;
  script runs the loader + schema-alignment tests — no new dependencies).

### Out of Scope

- Real secret resolution (E09-T05 owns `SecretManager`; loader returns a typed
  `{{ secret:… }}` error naming E09).
- OTel/logging/exporter consumer wiring (E01-T04/T05 consume `Config` sections).
- Full CI matrix (E17); production secret values (never committed).

## Normative Inputs

| E01-T03-R07 | `DatabaseConfig` MUST carry optional pool knobs (`max_open_conns`, `max_idle_conns`, `conn_max_lifetime_sec`; unset = driver/postgres-package defaults) with a pure `PoolSettings()` mapping covered by unit test. | must |

## Interfaces and Data

`func Load(base string, overlays ...string) (*Config, error)`; `Config` struct
with nested section structs; `SecretRefError` (typed, `Is`-compatible).
`APP_<SECTION>__<KEY>` env convention (case-insensitive keys, lowercased).

## Invariants and Failure Semantics

- Missing files in the chain: base missing → hard error; overlay missing → hard
  error (explicit paths must exist); `config.local.yaml` is the only optional
  file and is consulted ONLY via the caller's overlay list (never implicitly).
- Secrets never resolve here; secret-shaped values always fail closed.
- No secret values in committed YAMLs (refs only).
