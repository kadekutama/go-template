# Task Specification: E03-T10 — Top-ups (platform funding from bank)

**Task:** E03-T10
**Spec Status:** ready
**Author:** opencode-agent
**Reviewer:** repo-owner
**Last Updated:** 2026-09-14

## Objective

Ship top-up rules: verified-instrument gate, PENDING → SUCCEEDED/FAILED machine, reverse-settlement tracking, cancel policy.

## Scope

### In Scope

- `internal/domain/service/topup_service.go`: instrument verification gate, state machine, settlement-line shapes (reverse of payout), cancel-while-pending, idempotency key requirement.

### Out of Scope

- Bank verification provider, persistence (E07/E10); handlers.

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T10` for the backlog boundary.
- `docs/ledger-core.md §2` (external instruments are not chart accounts), `docs/fintech-ledger-features.md §3.4`, `docs/domain-events.md §3.13`.

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T10-R01 | Top-up MUST require a verified external bank instrument (`ACCOUNT_UNVERIFIED` otherwise); ledger-account `Verify` methods MUST NOT exist. | must |
| E03-T10-R02 | Amount MUST be positive with an idempotency key (`INVALID_TOPUP_AMOUNT` / `IDEMPOTENCY_KEY_REQUIRED` otherwise). | must |
| E03-T10-R03 | States MUST be PENDING → SUCCEEDED / FAILED; cancel allowed only while PENDING. | must |
| E03-T10-R04 | Failed top-ups MUST move nothing (no posting lines). | must |
| E03-T10-R05 | Settlement MUST be tracked like payouts in reverse with provider trace retention. | must |
| E03-T10-R06 | New code MUST import only stdlib + `internal/domain/...`. | must |
| E03-T10-R07 | Settlement bank-cash MUST differ from the credit account (journal no-ops rejected); top-up statuses live in `valueobject` with parsed transitions. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E03-T10-S01 | Verified instrument, positive amount | ValidateTopup | pass + funding lines |
| E03-T10-S02 | Unverified instrument | ValidateTopup | `ACCOUNT_UNVERIFIED` |
| E03-T10-S03 | Failed top-up | SettleTopup(FAILED) | no posting lines |
| E03-T10-S04 | PENDING top-up | Cancel | pass; non-pending cancel fails |
| E03-T10-S05 | Settlement with bank-cash == credit account | SettleTopup | `TOPUP_ACCOUNT_INVALID` |
