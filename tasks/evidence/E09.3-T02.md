## Implementation

`test/testcontainers/nats.go` now:

1. Waits for both `Server is ready` and the mapped `4222/tcp` host endpoint.
2. Builds the mapped URL and probes it with real `nats.Connect` calls, retrying
   for up to 10 seconds with a 500 ms per-attempt timeout and 500 ms polling.
3. Closes the probe connection on success.
4. Terminates the container and returns a wrapped error if the readiness bound
   expires.

`test/testcontainers/harness_test.go` now immediately connects to the returned
URL after `StartNATS` and closes that connection. The external connect assertion
is the packet's recorded exception because `StartNATS` returns only
`(*NATSHandle, error)` and connectability is its core contract.
