## Objective

Back the account/tenant API surface with application handlers implementing the `port.AccountUseCases` / `port.TenantUseCases` contracts over the account aggregate, onboarding service, and repository ports — tested with mocked ports.

## Scope

### In Scope

- `internal/application/command/{account,tenant}.go`: `AccountService` (open/update/freeze/unfreeze/close via `aggregate.Account` + `repository.AccountRepository`, idempotent through `UnitOfWork`), `TenantService` (provision via `service.ValidateOnboarding`, settings update) with a consumer-owned `TenantStore` (E07-T10 implements).
- `internal/application/query/{account,tenant}.go`: account Get/List, tenant Get, balance/entries/statement reads reuse E06-T13 services (no duplication).
- `internal/application/dto/{account,tenant}.go`: edge shapes for accounts + tenants.
- Tests with mocked ports/fakes: valid/invalid/boundary per handler, idempotent replay, version-conflict, auth denial.

### Out of Scope

- Posting/balance/entry writes (E06-T13), other bounded contexts (E06-T03–T05/T11), sagas (E06-T07), tenant persistence schema (E07-T10 implements `TenantStore`), API keys issuance (E09), RLS (E07-T02).

## Invariants and Failure Semantics

- Aggregates own transitions; handlers orchestrate (authz → idempotency → load → transition → persist + outbox → complete).
- Account writes go through the domain repository directly; E07 binds all stores into the commit transaction (same ambient-tx note as E06-T13 evidence).
- Tenant persistence lands via `TenantStore` (E07-T10 schema); duplicate names fail closed on the pre-read list.
- Unknown commit outcomes resolve via identical resubmission, never blind retry.

## Change Surface

**Owns:** `internal/application/command/{account,tenant}.go`, `query/{account,tenant}.go`, `dto/{account,tenant}.go` + tests.
**Coordinates:** `internal/application/port` (read-only), domain aggregate/service/repository (read-only) **plus one additive domain loader**: `aggregate.LoadAccount` (`internal/domain/aggregate/account.go`) — no aggregate has a rehydration path, so stored accounts cannot transition without duplicating rules in handlers; the loader is a pure constructor with empty events, no behavior change to existing paths.
**Must Not Touch:** other E06 tasks' files, domain logic beyond the loader, infrastructure, task statuses outside E06-T02, Git remotes.
