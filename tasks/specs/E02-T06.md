## Objective

Ship every typed domain event in `docs/domain-events.md §3.1–§3.15` on the E02-T01 envelope with exact `EventType()` strings (American spelling), so aggregates (E02-T03–T05, E03–E05) emit catalog types and every `api-contracts.md §10` webhook maps to an event.

## Scope

### In Scope

- `internal/domain/event/typed.go`: generic `TypedEvent[P]` (embeds `BaseEvent`, overrides `Payload()` with the typed value) + `newTyped` constructor helper validating envelope inputs.
- Catalog payloads + constructors, grouped per backlog file surface:
  - `account.go`: `account.created/updated/frozen/unfrozen/closed/verified/balance.changed.v1` (+ `tenant.created.v1`, `pii.erased.v1` tenant-identity events; backlog lists no tenant/privacy file).
  - `transaction.go`: `transaction.posted/reversed/failed/pending.v1` (posted = accepted immutable Posting; pending/failed are workflow notifications, never ledger mutations).
  - `transfer.go`: `transfer.created/completed/failed/canceled/batch.received/batch.completed.v1`.
  - `payment.go`: `payment_intent.created/succeeded/failed/canceled/requires_action.v1`.
  - `capture.go`: `payment.captured/settled.v1` (capture/settlement pair).
  - `refund.go`: `refund.created/succeeded/failed.v1`; `payout.go`: `payout.created/pending/paid/failed.v1`.
  - `reconciliation.go`: `reconciliation.run.started/completed/break.found/break.resolved/break.acknowledged.v1`.
  - `period.go`: `period.opened/closed/reopened.v1`; `fx.go`: `fx.rate.updated.v1`.
  - `fee.go`: `fee.assessed/collected.v1`; `report.go`: `report.generated.v1` (application-originated, same envelope).
  - `dispute.go`: `dispute.opened/closed.v1`; `topup.go`: `topup.succeeded/failed.v1`.
- Doc-exact payload structs where the catalog gives them (`AccountCreated`, `BalanceChanged`, `TransactionPosted/Entry`, `TransactionReversed`, `PaymentSettled`, `ReportGenerated`, `DisputeOpened/Closed`, `TopUp`, `TenantCreated`, `PIIErased`); minimal trigger-faithful payloads elsewhere (IDs + tenant + status/amounts + timestamps).
- `catalog_test.go`: every catalog type asserts its exact `EventType()` string, envelope accessors, and payload typing.

### Out of Scope

- Aggregate emission wiring (E02-T03–T05 append these events to uncommitted buffers; emission-proof tests live in those suites + E02-T09).
- Wire serialization, outbox publication (E08 adapter), webhook allow-listed projections (API tasks).
- New event types beyond the catalog (E03–E05 reuse these; additions need packet updates).

## Interfaces and Data

```go
// typed.go
type TypedEvent[P any] struct {
    BaseEvent
    typed P
}
func (e TypedEvent[P]) Payload() any { return e.typed }
func (e TypedEvent[P]) Typed() P { return e.typed } // typed accessor, no collision
func newTyped[P any](eventType, eventID, aggregateID, aggregateType string,
    occurredAt time.Time, version, seq int64, payload P, meta EventMetadata) (TypedEvent[P], error)
// per-area: payload structs + New<Name>(...) (TypedEvent[<Payload>], error)
```

- `Payload()` returns the typed struct value (immutable by convention; maps/slices inside payloads are copied at construction where present, e.g. `TransactionReversed.Metadata`).
- Versioning: new schema versions are new constructors + new `EventType()` strings; existing strings never change.
- No wire/migration/config change.

## Invariants and Failure Semantics

- Catalog adds no new ordering or delivery semantics: sequence-per-aggregate ordering and at-least-once outbox + effectively-once inbox live in `ledger-core.md §9` / E07–E08.
- Webhook projections are allow-listed downstream; catalog payloads may carry internal IDs that projections must redact (E08/API).
- `pii.erased` never becomes a public webhook without a separately approved projection.
- Reversal events reference the original posting; they never mutate it.
