# Task Specification: E09-T03 — Casbin RBAC/ABAC enforcement

**Task:** E09-T03
**Spec Status:** ready
**Author:** muse-spark

**Last Updated:** 2026-09-23

## Objective

Deliver tenant-scoped authorization behind `port.Authorizer` with Casbin v2.8.0 (RBAC + ABAC amount thresholds), DB-backed hot-reloadable policies, and decision audit hooks.

## Scope

### In Scope

- `internal/infrastructure/auth/rbac/` package: `model.conf`, embedded default policies, enforcer wrapper, `loader.go` (replace-without-restart), threshold ABAC (`amountMinor` approver rule), audit hook seam.
- `Module() fx.Option` exposing `port.Authorizer`.
- Unit tests (cross-tenant deny, threshold approver, reload, cancel).

### Out of Scope

- JWT validation (E09-T01), HTTP/gRPC middleware wiring (E11–E13 consume the port), E04-T02 approval workflow itself.

## Normative Inputs

- `tasks/epics/E09-identity-security.md#E09-T03` for the backlog boundary.
- `SPEC.md §7.4` (Casbin v2.8.0) and `SPEC.md §2` (RBAC/ABAC hybrid).
- `internal/application/port/authz.go` (`Subject`, `Authorizer` contract).
- `docs/user-journeys.md §5` (auth matrix touchpoints).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E09-T03-R01 | `Authorize` MUST deny cross-tenant access even with otherwise valid subject and MUST enforce role/resource/action grants. | must |
| E09-T03-R02 | Above-threshold money actions MUST require an approver distinct from the resolver (ABAC `amountMinor` + `approver` attributes). | must |
| E09-T03-R03 | Policy reload MUST apply without restart and MUST be concurrency-safe for in-flight checks. | must |
| E09-T03-R04 | Every decision MUST emit to the audit hook seam (allow + deny with subject/action/resource). | must |
| E09-T03-R05 | The adapter MUST implement `port.Authorizer` exactly and MUST expose `Module() fx.Option`. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E09-T03-S01 | Same-tenant granted role | `Authorize` | Nil error + audit allow |
| E09-T03-S02 | Cross-tenant valid JWT subject | `Authorize` | Forbidden error + audit deny |
| E09-T03-S03 | Above-threshold with approver == resolver | `Authorize` | Denied; distinct approver passes |
| E09-T03-S04 | Policy replaced at runtime | `Authorize` before/after | Old denies, new allows, no restart |
| E09-T03-S05 | Canceled context | `Authorize` | Context error |

```go
// Module() fx.Option
```

## Invariants and Failure Semantics

- Default deny; denial is an error, never a boolean the caller can ignore.
- Strong read of policy state; reloads never tear in-flight checks (RWMutex).
- No policy content in errors beyond action/resource names.

**Notes:** Author/approver are different persons as required for authorization work.
**Amendment 2026-09-23 (durable-boundary review, ADR-020):** The wrapper holds
a `casbin.SyncedEnforcer` (the library's own synchronized type) instead of a
hand-rolled `RWMutex` around `casbin.Enforcer`. Policy truth stays the durable
loader seam (checked-in CSV + hot `Reload`); threshold ABAC stays a pure
function. No app mutexes.
**Amendment 2026-09-25 (review round 3, Antigravity Agent):** Added `DBPolicyLoader` with
`CasbinRuleModel` (`casbin_rules` table in PostgreSQL) to support durable database policy storage
in addition to `CSVLoader`. Added `Enforcer.ReloadFrom(loader PolicyLoader)` for dynamic hot reload.
Fixed `CSVLoader` variable column parsing with `FieldsPerRecord = -1`. Added full table-driven tests.

**Amendment 2026-10-01 (GLM review fix round, CR-005/CR-006):** `NewEnforcer`
rejects non-positive `ThresholdAmountMinor` at construction (no silent unguarded
mode; an explicit opt-out remains a future packet decision, not the zero value).
`20261001000010_casbin_rules.sql` creates the standard six-column Casbin table as
an explicitly GLOBAL table with no tenant RLS policy: tenant scope lives in the
dom columns and is enforced by the matcher, so per-tenant RLS would be both
inexpressible and redundant. Rollback: drop the migration (re-hash `atlas.sum`),
restore zero-threshold behavior.
