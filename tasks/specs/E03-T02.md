# Task Specification: E03-T02 — Refund domain service (window, amount, reversal linkage)

**Author:** opencode-agent
**Reviewer:** repo-owner
**Last Updated:** 2026-09-14

## Objective

Ship pure refund rules: window, amount caps against prior refunds, reversal linkage, and fee-refund policy passthrough.

## Scope

### In Scope

- `internal/domain/service/refund_service.go`: `OriginalExists`, `RefundAmountValid`, `RefundWindowValid`, `AccountActive` enforcement; refund-acceptance + customer-settlement posting-line construction linked to original; fee-refund policy result (explicit, never assumed proportion).

### Out of Scope

- Persistence, idempotency records, provider calls (E07/E10); handlers/API (E06/E11).

## Normative Inputs

- `tasks/epics/E03-money-movement.md#E03-T02` for the backlog boundary.
- `docs/ledger-core.md §3, §6.4` (reversal linkage, fee policy not proportional, immutable originals).
- `docs/money-flow.md §2.4` (refund flow), `docs/domain-events.md §3.5` (`refund.created/succeeded/failed`).

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| E03-T02-R01 | Refund MUST require the original payment exists (`ORIGINAL_NOT_FOUND` otherwise). | must |
| E03-T02-R02 | Refund amount MUST be positive and ≤ original − prior refunds (`REFUND_EXCEEDS_ORIGINAL` otherwise). | must |
| E03-T02-R03 | Refund MUST fall inside the configurable window (default 90d) from original (`REFUND_WINDOW_EXPIRED` otherwise). | must |
| E03-T02-R04 | Both merchant accounts MUST be ACTIVE (`ACCOUNT_FROZEN`/`ACCOUNT_CLOSED` otherwise). | must |
| E03-T02-R05 | Refund MUST construct acceptance (DR merchant payable / CR refunds payable) + settlement (DR refunds payable / CR bank cash) lines linked to the original posting ID; original entries stay immutable; the three accounts MUST be pairwise distinct. | must |
| E03-T02-R06 | Fee refunds MUST use the explicit processor/platform policy result, never an assumed proportion. | must |
| E03-T02-R07 | All refund accounts MUST be ACTIVE and carry the refund asset code (`ACCOUNT_FROZEN`/`ACCOUNT_CLOSED`/`CURRENCY_MISMATCH` otherwise). | must |
| E03-T02-R08 | New code MUST import only stdlib + `internal/domain/...`. | must |

## Executable Scenarios

| ID | Given | When | Then |
|----|-------|------|------|
| E03-T02-S01 | Original 10000, prior 3000, refund 7000 in window | ValidateRefund | pass + lines linked to original |
| E03-T02-S02 | Refund exceeds original − priors | ValidateRefund | `REFUND_EXCEEDS_ORIGINAL` |
| E03-T02-S03 | Refund after window | ValidateRefund | `REFUND_WINDOW_EXPIRED` |
| E03-T02-S04 | Missing original | ValidateRefund | `ORIGINAL_NOT_FOUND` |
| E03-T02-S05 | Refund with identical acceptance accounts or mismatched asset | ValidateRefund | rejected (distinct accounts, `CURRENCY_MISMATCH`) |
