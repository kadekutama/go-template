## Objective

Move the scheduler pin from deprecated gocron v1.5.0 to gocron v2 before E14 writes cron code, and realign the E14 contract so worker implementation starts on the v2 API.

## Scope

### In Scope

- `go.mod` / `go.sum`: `github.com/go-co-op/gocron v1.5.0` → `github.com/go-co-op/gocron/v2 v2.22.0`, `go mod tidy`.
- `internal/shared/deps/deps.go`: blank import `github.com/go-co-op/gocron` → `github.com/go-co-op/gocron/v2`.
- `SPEC.md §2` + `§8.4` version rows v1.5.0 → v2.
- `tasks/epics/E14-workers.md`: version strings + scheduler-construction notes only (no job logic).
- `docs/architecture/ADR-022-gocron-v2.md`: v1→v2 API delta record (creation, job definition, start/stop, error returns, `j.ID()`), E14 construction contract, rollback (re-pin v1).
- `internal/shared/deps/deps_test.go`: version-proof test constructs a scheduler, adds an unstarted no-op job, and shuts down cleanly.

### Out of Scope

- gocron-ui surface (E09.1-T02), egress limiter (E09.1-T03), single-flight (E09.1-T04).
- E14 job implementations, leader-election behavior changes, etcd/Redlock tuning (E14-T01 owns).
- Resty or any HTTP client change (owner decision: no Resty).
