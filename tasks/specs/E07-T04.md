## Objective

One-command seeded environment for onboarding (§2.1) and sandbox DX plus deterministic fixtures reused by `test/fixtures`.

## Scope

### In Scope

- `database/seed/{dev,fixtures}.go`: dev tenant + default chart (operating/fee/suspense × USD/EUR/IDR) + demo transactions covering every money-flow §2 pattern.
- `scripts/db/{seed,reset}.sh` + `make db-seed`/`make db-reset` wiring (drop + migrate + seed).
- Test fixture builder package reused by `test/fixtures`.
- Idempotent seed (run twice, same result).

### Out of Scope

- Production data/backfills (none exist); migration content (T01/T10); backup (T05).
- Real user/PII data (demo values only, never production payloads).

## Normative Inputs

- `tasks/epics/E07-persistence.md#E07-T04` for the backlog boundary.
- `docs/user-journeys.md §2.1` (onboarding seed), `docs/fintech-ledger-features.md §12` (sandbox DX), `docs/money-flow.md §2` (pattern coverage).
- `test/fixtures/*` (stable IDs this task reuses).
